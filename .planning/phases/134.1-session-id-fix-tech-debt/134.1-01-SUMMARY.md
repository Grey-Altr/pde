## Decisions Made

- **PDE_RELAY_SCRIPT_OVERRIDE required in integration tests**: When `CLAUDE_PLUGIN_ROOT` is a temp dir, there is no `bin/lib/relay.cjs` in it. The relay daemon spawned by the hook uses `path.join(pluginRoot, 'bin', 'lib', 'relay.cjs')` — this path doesn't exist in a temp dir. The integration test must set `PDE_RELAY_SCRIPT_OVERRIDE` to the worktree's relay.cjs to avoid silent daemon failures.
- **Valid PDE event format required**: Events written to NDJSON must include `schema_version`, `ts` (ISO string), `event_type` to pass `WireEnvelopeSchema.safeParse()`. Tests using `ts: Date.now()` (number) fail schema validation and no events are relayed.
