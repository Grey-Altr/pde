    **Add to bin/lib/presentation.cjs:**

    **Function 5: extractGitVelocity(cwd)**
    - Use `execGit(cwd, ['log', '--pretty=format:%as', '--no-merges'])` for commit dates
    - If exitCode !== 0, return `{ unavailable: true, reason: 'git log failed' }`
    - Count total commits from stdout lines
    - Filter for dates within last 30 days for commits_last_30_days
    - Use `execGit(cwd, ['shortlog', '-sn', '--no-merges', 'HEAD'])` for contributors -- parse `\s+\d+\s+(.+)` lines
    - Use `execGit(cwd, ['log', '--pretty=format:', '--stat', '--no-merges'])` for LOC estimate -- sum insertions from `(\d+) insertion` matches
    - Return `{ total_commits, commits_last_30_days, contributors, estimated_loc_added }`

    **Function 6: extractCostTiming(cwd)**
    - Walk all phase directories (both `.planning/phases/` and archived via getArchivedPhaseDirs if available, or manual readdir of `milestones/*/`)
    - For each dir, find *-SUMMARY.md files, read with extractFrontmatter
    - Extract `duration` field from frontmatter (format: "27min" -- parse number before "min")
    - Count sessions (each SUMMARY.md is one session)
    - Sum durations, compute average
    - If zero SUMMARY.md files found, return `{ unavailable: true, reason: 'no session summary files found' }`
    - Return `{ session_count, total_duration_min, phases_with_timing, average_phase_duration_min }`
    - DO NOT read from /tmp or os.tmpdir() -- NDJSON event files are ephemeral

    **Function 7: extractBlockers(cwd)**
    - Read `.planning/STATE.md` via safeReadFile. If null, return `{ blockers: [], risks: [] }`
    - Parse `### Blockers/Concerns` section -- extract each `- [Phase N]: text` or `- [Source]: text` line
    - Parse `### Pending Todos` section for additional items
    - Classify items: those mentioning "risk" or "concern" -> risks array, others -> blockers array
    - Each item: `{ text: 'full line text', phase: 'N' (extracted from [Phase N] tag), type: 'blocker'|'concern'|'risk' }`
    - Empty sections are valid (return empty arrays, NOT unavailable sentinel)

    **Function 8: extractVerification(cwd)**
    - Walk all phase directories (current + archived)
    - For each dir, look for *-VERIFICATION.md files
    - Parse each: count `- [x]` (ac_pass) and `- [ ]` (ac_fail) checkboxes
    - Check for `**Overall: ACHIEVED**` or `**Overall: NOT ACHIEVED**` or `**Goal.*ACHIEVED**` pattern
    - Track phases_verified (count of dirs with VERIFICATION.md), phases_achieved, phases_not_achieved
    - phases_missing_verification = total phase dirs minus phases_verified
    - Return `{ phases_verified, phases_achieved, phases_not_achieved, phases_missing_verification, results: [...] }`

    **Function 9: extractResearch(cwd)**
    - Count files in `.planning/research/` directory (project-level research)
    - Extract topic names from filenames (e.g., ARCHITECTURE.md -> "ARCHITECTURE")
    - Walk phase directories, count those containing *-RESEARCH.md files
    - Return `{ project_research_files, topics, phase_research_count }`
    - If `.planning/research/` does not exist, set project_research_files: 0, topics: []

    **Function 10: extractDecisions(cwd)**
    - Read STATE.md `### Decisions` section -- parse each `- [Source]: text` line
    - Walk phase directories, read SUMMARY.md frontmatter `key-decisions` arrays
    - Combine into single array: `{ phase: 'N', summary: 'text', rationale: 'from source tag' }`
    - Return the array (empty array is valid, NOT unavailable sentinel)
