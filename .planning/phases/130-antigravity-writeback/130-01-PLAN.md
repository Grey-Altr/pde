  <behavior>
    hexToOklch(hexStr):
    - Reverse of oklchToHex pipeline:
      1. Parse hex: extract R, G, B as 0-255 integers
      2. Handle 3-char shorthand: #rgb → #rrggbb
      3. Normalize to 0-1: r/255, g/255, b/255
      4. Remove gamma: linearize sRGB (inverse of gamma function in oklchToHex)
         ```
         c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4)
         ```
      5. linear sRGB → LMS (inverse of the matrix in oklchToHex lines 285-287)
         Use the forward matrix: M = [[0.4122214708, 0.5363325363, 0.0514459929], ...]
      6. LMS → OKLAB: cube root of LMS, then matrix multiply
         Use the forward matrix: M2 = [[0.2104542553, 0.7936177850, -0.0040720468], ...]
      7. OKLAB → OKLCH: L = l, C = sqrt(a² + b²), H = atan2(b, a) * 180/π
         Handle H < 0 by adding 360
      8. Return: `oklch(${L.toFixed(4)} ${C.toFixed(4)} ${H.toFixed(4)})`

    writeBackDesignTokens(planningDir, editorColors, opts):
    - editorColors: array of { name, hex, role } from parseDesignMd output
    - Read design-manifest.json
    - For each editor color:
      - Find matching token in manifest.tokens.color by role name (case-insensitive)
      - Convert hex to OKLCH via hexToOklch
      - Check round-trip precision: oklchToHex(newOklch) vs original hex
      - If delta > 0.001: log warning to stderr
      - Update token.$value with new OKLCH string
      - Preserve ALL other fields ($type, $description, $extensions, etc.)
    - Write updated manifest atomically (write-rename)
    - Call emitAll(opts.cwd) to re-normalize all editor files
    - Return: { updated: number, warnings: number }
