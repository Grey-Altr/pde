  <action>
    Create `bin/lib/video-pipeline/compose.cjs`:

    1. `function extractTokens(designDir)`:
       - `const designPath = designDir || path.join(process.cwd(), '.planning/design');`
       - Glob for `SYS-*.json` files in designPath
       - For each file, `JSON.parse(fs.readFileSync(...))` and walk DTCG token structure
       - Extract color tokens (look for `$type: 'color'` and `$value`) into `colors` object
       - Extract font tokens (look for `$type: 'fontFamily'` and `$value`) into `fonts` object
       - Map to simplified structure: `{ colors: { background, primary, accent }, fonts: { heading, body } }`
       - If no SYS-*.json found OR parsing fails: return DEFAULT_TOKENS (hardcoded fallbacks matching BrandedVideo.tsx defaults)
       - Export for testing

    2. `async function composeVideo({ title = 'Product Demo', subtitle = '', slug = 'branded', resolution = '1920x1080', durationFrames = 150, designDir, assetsDir })`:
       - `const { resolveResolution, saveVideoAsset } = require('./assets.cjs');`
       - `const { width, height } = resolveResolution(resolution);`
       - `const tokens = extractTokens(designDir);`
       - Write props to temp JSON file: `{ ...tokens, title, subtitle, durationInFrames: durationFrames }`
       - `const remotionDir = path.join(__dirname, 'remotion');`
       - `const outputPath = path.join(os.tmpdir(), '${slug}-${Date.now()}.mp4');`
       - `execFileSync('npx', ['remotion', 'render', 'index.ts', 'branded', outputPath, '--codec', 'h264', '--width', String(width), '--height', String(height), '--props', propsPath], { cwd: remotionDir, stdio: 'inherit' });`
       - Clean up temp props file
       - Call `saveVideoAsset({ slug, mp4Path: outputPath, dimensions: { width, height }, source: 'remotion-branded', params: { title, subtitle, durationFrames, resolution }, assetsDir })`
       - Return `{ path, meta }`

    3. Export: `{ composeVideo, extractTokens }`

    **Tests** (`tests/phase-167/compose.test.mjs`):
