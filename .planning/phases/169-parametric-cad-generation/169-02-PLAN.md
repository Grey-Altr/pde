### cad -- Parametric CAD Generation

Generate a parametric CadQuery Python script from a product description, execute it via Python subprocess, and export a STEP file for engineering handoff.

**Requires:** CadQuery installed in a Python venv. Set `CADQUERY_PYTHON` env var to the venv python path.

```
/pde:3d cad --description <text> [--slug <slug>]
```

Options:
- `--description` -- Text description of the hardware product to model (required)
- `--slug` -- Identifier slug for output filename (default: `cad-model`)

Output: JSON metadata for the generated STEP asset. The STEP file, source CadQuery script (.cq.py), and metadata sidecar are saved to `.planning/design/3d/`.

Example:
```
/pde:3d cad --description "rectangular electronics enclosure 120x80x40mm with 3mm walls and rounded edges" --slug enclosure
/pde:3d cad --description "L-shaped mounting bracket 50x30mm with 4mm holes" --slug bracket
```

Setup (one-time):
```bash
python3.11 -m venv ~/cadquery-env
source ~/cadquery-env/bin/activate
pip install cadquery
export CADQUERY_PYTHON=~/cadquery-env/bin/python3
```
```
