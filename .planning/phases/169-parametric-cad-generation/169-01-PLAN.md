Create `bin/lib/3d-pipeline/cad.cjs` as a CJS module with `'use strict';` and JSDoc comments. NOTE: This module uses `execFileSync` (not `exec`) which passes arguments as an array and does NOT invoke a shell -- this is the safe subprocess pattern that prevents command injection, consistent with the existing video pipeline pattern.

**Constants:**
```javascript
const PYTHON_BIN_KEY = 'CADQUERY_PYTHON';
const DEFAULT_PYTHON = 'python3';
const SUBPROCESS_TIMEOUT = 60000;
const INSTALL_MSG = 'CadQuery not found. Install:\n  python3.11 -m venv ~/cadquery-env\n  source ~/cadquery-env/bin/activate\n  pip install cadquery\n  export CADQUERY_PYTHON=~/cadquery-env/bin/python3';
```

**Requires:**
```javascript
const { execFileSync } = require('child_process');
const fs = require('fs');
const path = require('path');
const os = require('os');
```

**Function: checkCadQuery(pythonBin, _execFn)**
- `const execFn = _execFn || execFileSync;`
- Try: `execFn(pythonBin, ['-c', 'import cadquery'], { encoding: 'utf8', timeout: 10000 });` return `true`
- Catch: return `false`

**Function: getPythonVersion(pythonBin, _execFn)**
- `const execFn = _execFn || execFileSync;`
- Try: run `execFn(pythonBin, ['--version'], { encoding: 'utf8', timeout: 5000 })`
- Parse with `/Python (\d+)\.(\d+)/` -- return `{ major: +m[1], minor: +m[2] }` or `null`
- Catch: return `null`

**Function: validateStep(filePath)**
- If `!fs.existsSync(filePath)` return `{ valid: false, reason: 'file does not exist' }`
- If `fs.statSync(filePath).size === 0` return `{ valid: false, reason: 'file is empty' }`
- `const header = fs.readFileSync(filePath, 'utf8').slice(0, 50);`
- If `!header.includes('ISO-10303-21')` return `{ valid: false, reason: 'missing ISO-10303-21 header' }`
- Return `{ valid: true, size: fs.statSync(filePath).size }`

**Function: saveCADAsset({ slug, stepPath, scriptContent, params, assetsDir })**
- `const baseDir = assetsDir || require('./assets.cjs').THREE_D_DIR;`
- `fs.mkdirSync(baseDir, { recursive: true });`
- `const timestamp = Date.now();`
- `const stepDest = path.join(baseDir, slug + '-' + timestamp + '.step');`
- `const scriptDest = path.join(baseDir, slug + '-' + timestamp + '.cq.py');`
- `const metaDest = path.join(baseDir, slug + '-' + timestamp + '.meta.json');`
- `fs.copyFileSync(stepPath, stepDest);`
- `fs.writeFileSync(scriptDest, scriptContent);`
- Build meta object: `{ source_script: path.relative(process.cwd(), scriptDest), params: params || {}, timestamp: new Date(timestamp).toISOString(), file_size: fs.statSync(stepDest).size, step_version: 'ISO-10303-21', slug, step_path: path.relative(process.cwd(), stepDest) }`
- `fs.writeFileSync(metaDest, JSON.stringify(meta, null, 2));`
- Return `{ stepPath: stepDest, metaPath: metaDest, scriptPath: scriptDest, meta }`

**Function: runCadScript({ pythonBin, scriptContent, outputStepPath, _execFn })**
- `const execFn = _execFn || execFileSync;`
- `const tmpScript = path.join(os.tmpdir(), 'pde-cad-' + Date.now() + '.py');`
- `try { fs.writeFileSync(tmpScript, scriptContent); execFn(pythonBin, [tmpScript, outputStepPath], { encoding: 'utf8', timeout: SUBPROCESS_TIMEOUT, cwd: process.cwd() }); } finally { if (fs.existsSync(tmpScript)) fs.unlinkSync(tmpScript); }`

**Function: generateScript(description)**
- Returns a string containing a CadQuery Python script with:
  - `import cadquery as cq` and `import sys`
  - `PARAMS = { "length": 80.0, "width": 50.0, "height": 25.0 }` (default box dimensions)
  - `result = cq.Workplane("XY").box(PARAMS["length"], PARAMS["width"], PARAMS["height"])`
  - `output_path = sys.argv[1] if len(sys.argv) > 1 else "output.step"`
  - `cq.exporters.export(result, output_path, exportType="STEP")`
  - `print(f"STEP exported: {output_path}")`
  - The description parameter is included as a Python comment at top for documentation
  - NOTE: In production use, Claude (the executing agent) typically provides _scriptContent directly with a custom script tailored to the description. This default script is a fallback.

**Function: generateCAD({ description, slug, assetsDir, _execFn, _scriptContent })**
- `const pythonBin = process.env[PYTHON_BIN_KEY] || DEFAULT_PYTHON;`
- Check CadQuery: `if (!checkCadQuery(pythonBin, _execFn)) throw new Error(INSTALL_MSG);`
- Check Python version: `const ver = getPythonVersion(pythonBin, _execFn); if (ver && (ver.major < 3 || (ver.major === 3 && ver.minor < 10))) throw new Error('Python 3.10+ required for CadQuery, found ' + ver.major + '.' + ver.minor);`
- `const scriptContent = _scriptContent || generateScript(description);`
- `const tmpStep = path.join(os.tmpdir(), 'pde-cad-' + Date.now() + '.step');`
- `try { runCadScript({ pythonBin, scriptContent, outputStepPath: tmpStep, _execFn }); }`
- Validate: `const v = validateStep(tmpStep); if (!v.valid) throw new Error('STEP validation failed: ' + v.reason);`
- Extract params from scriptContent via regex: `const paramsMatch = scriptContent.match(/PARAMS\s*=\s*\{([^}]+)\}/);` then parse key-value pairs with `/["'](\w+)["']\s*:\s*([\d.]+)/g`
- `const result = saveCADAsset({ slug: slug || 'cad-model', stepPath: tmpStep, scriptContent, params, assetsDir });`
- `finally { if (fs.existsSync(tmpStep)) fs.unlinkSync(tmpStep); }`
- Return result
