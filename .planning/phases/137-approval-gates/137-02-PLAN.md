    Props interface:
    ```typescript
    interface ApprovalCardProps {
      event: WireEnvelope;         // The pending approval_request event
      sessionId: string;           // For the POST request
      onResponded?: () => void;    // Optional callback after response submitted
    }
    ```

    The component renders a full-width Card (import from `@/components/ui/card`) with:

    1. **Header section** -- amber/warning styling:
       - Title: "Approval Required" in bold
       - Subtitle: the event's context field -- read from `(event as Record<string, unknown>).context` or fallback to `event.event_type`
       - Phase/plan context: read `(event as Record<string, unknown>).phase_name` and `(event as Record<string, unknown>).plan_name` if present
       - Timestamp: format `event.ts` as relative time

    2. **Action buttons row** -- two buttons side by side:
       - "Approve" button: green styling (`bg-green-600 hover:bg-green-700 text-white`), `min-h-[44px]` (D-08)
       - "Deny" button: red styling (`bg-red-600 hover:bg-red-700 text-white`), `min-h-[44px]` (D-08)
       - Both buttons are `AlertDialog.Trigger` elements that set which action is pending

    3. **AlertDialog confirmation** (D-06) -- uses `@base-ui/react/alert-dialog`:
       ```tsx
       import * as AlertDialog from '@base-ui/react/alert-dialog';
       ```
       - `AlertDialog.Root` with `open` / `onOpenChange` controlled state
       - `AlertDialog.Portal` wrapping both Overlay and Popup (REQUIRED for z-index escape)
       - `AlertDialog.Overlay`: `className="fixed inset-0 bg-black/50 z-50"`
       - `AlertDialog.Popup`: centered modal with `className="fixed left-1/2 top-1/2 -translate-x-1/2 -translate-y-1/2 z-50 w-[90vw] max-w-md rounded-lg bg-background p-6 shadow-lg"`
       - `AlertDialog.Title`: "Confirm {Approve|Deny}" depending on pending action
       - `AlertDialog.Description`: "Are you sure you want to {approve|deny} this request? This action cannot be undone."
       - Two buttons inside the popup:
         - Confirm button: calls `handleSubmit()`, `min-h-[44px]`, styled green for approve / red for deny
         - Cancel button: `AlertDialog.Close`, `min-h-[44px]`, neutral styling

    4. **Submit handler** `handleSubmit`:
       - Set `submitting` state to true
       - POST to `/api/approval-response` with body `{ session_id: sessionId, approval_id: event.approval_id, action: pendingAction }`
       - On success: set `submitted` state to true, close dialog, call `onResponded?.()`
       - On error: set error state, show inline error message
       - Use try/catch, set submitting to false in finally

    5. **Submitted state**: When `submitted` is true, render a muted card showing "Approval submitted" with a checkmark or "Denied" with an x, instead of the action buttons.

    Card wrapper styling: `border-amber-500/50 bg-amber-500/5` to make it visually prominent (D-07: appears at top of session detail).

    Do NOT use shadcn AlertDialog. Do NOT use any `@radix-ui` imports. Use `@base-ui/react/alert-dialog` exclusively.
