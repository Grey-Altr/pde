  <action>
Create `bin/lib/context-sync.cjs` as a single CJS module (zero npm deps) with these components:

**1. SHA-256 composite hash function (`computeSourceHash`):**
- Use `crypto.createHash('sha256')` (built-in, same pattern as manifest.cjs line 20-27)
- Hash concatenation of: PROJECT.md, STATE.md, DESIGN-STATE.md, design-manifest.json, and all handoff/*.md files (sorted by name)
- Return 64-char hex string

**2. PDE-GENERATED header function (`makeHeader`):**
- Format: `<!-- PDE-GENERATED | hash:{sourceHash} | generated:{isoTimestamp} -->`
- Every generated file gets this as its first line

**3. IR builder (`buildContextIR(planningDir)`):**
- Read these source files via `safeReadFile` from core.cjs:
  - `.planning/PROJECT.md` — extract project name (first `# ` heading), product type, tech stack section, constraints section
  - `.planning/STATE.md` — extract current phase, milestone
  - `.planning/design/DESIGN-STATE.md` — extract pipeline status, current stage, completion %
  - `.planning/design/design-manifest.json` — parse JSON, extract artifact list, design coverage flags, token summary
  - `.planning/design/handoff/*.md` — glob for handoff specs, extract component names and prop interfaces
- Return IR object:
```javascript
{
  projectName: string,        // from PROJECT.md first heading
  productType: string,        // from manifest or PROJECT.md
  techStack: string,          // tech stack section text
  projectSummary: string,     // first 2 paragraphs of PROJECT.md after heading
  designTokens: string,       // summarized token info from manifest
  componentCatalog: string,   // component names + brief from handoff
  pipelineStatus: string,     // from DESIGN-STATE.md
  constraints: string,        // constraints section from PROJECT.md
  sourceHash: string,         // SHA-256 composite hash
  generatedAt: string,        // ISO 8601 timestamp
}
```
- Use `safeReadFile` for all reads (returns null on missing, no crashes)
- For extracting sections from markdown: simple regex `## Section Name` to next `## ` or EOF
- For extracting project name: first line matching `/^# (.+)/`

**4. AGENTS.md emitter (`emitAgentsMd(ir, projectRoot)`):**
- Check ownership before writing: if AGENTS.md exists AND does NOT contain `<!-- PDE-GENERATED`, skip with `{ skipped: true, reason: 'User-authored AGENTS.md detected' }`
- Content structure:
```
<!-- PDE-GENERATED | hash:{hash} | generated:{ts} -->
# {projectName}

## Project Overview
{projectSummary}

## Tech Stack
{techStack}

## Design System
{designTokens}

## Component Catalog
{componentCatalog}

## Conventions
{constraints}
```
- Write to `{projectRoot}/AGENTS.md`

**5. Cursor .mdc emitter (`emitCursorRules(ir, projectRoot)`):**
- Create `.cursor/rules/` directory with `fs.mkdirSync(path, { recursive: true })`
- Generate 5 .mdc files, each with PDE-GENERATED header INSIDE the body (after frontmatter):

| File | description | globs | alwaysApply | Body Content |
|------|-------------|-------|-------------|--------------|
| `pde-project.mdc` | `PDE project context` | (omit) | `true` | projectName, productType, projectSummary, constraints |
| `pde-design-tokens.mdc` | `PDE design token reference` | `*.css,*.scss,*.tsx,*.jsx` | `false` | designTokens |
| `pde-components.mdc` | `PDE component catalog` | `src/components/**` | `false` | componentCatalog |
| `pde-architecture.mdc` | `PDE architecture patterns` | `src/**` | `false` | techStack, constraints |
| `pde-pipeline.mdc` | `PDE pipeline status` | (omit) | `true` | pipelineStatus |

- YAML frontmatter format (simple string concatenation, NOT a YAML library):
```
---
description: {description}
globs: {globs}         # only if globs is set
alwaysApply: {bool}
---
```
- Keep description values simple: no colons, quotes, or special chars

**6. Legacy .cursorrules emitter (`emitCursorrules(ir, projectRoot)`):**
- Single file at project root, plain markdown (no YAML frontmatter)
- Content: PDE-GENERATED header + project context + tech stack + design tokens + component catalog + constraints
- Write to `{projectRoot}/.cursorrules`

**7. GEMINI.md hierarchy emitter (`emitGeminiMd(ir, projectRoot, planningDir)`):**
- Generate 3 files plus 2 auxiliary .md summaries for @file imports:

a) `{projectRoot}/GEMINI.md` — project root:
```
<!-- PDE-GENERATED | hash:{hash} | generated:{ts} -->
# {projectName}

## Project Context
{projectSummary}

## Tech Stack
{techStack}

## Design System
@.planning/design/pde-design-summary.md

## Pipeline Status
@.planning/pde-pipeline-summary.md

## Conventions
{constraints}
```

b) `{planningDir}/GEMINI.md` — .planning/ directory:
```
<!-- PDE-GENERATED | hash:{hash} | generated:{ts} -->
# PDE Planning Context

## Pipeline Status
{pipelineStatus}

## Project Requirements
{brief requirements summary}
```

c) `{planningDir}/design/GEMINI.md` — .planning/design/ directory:
```
<!-- PDE-GENERATED | hash:{hash} | generated:{ts} -->
# PDE Design System

## Design Tokens
{designTokens}

## Component Catalog
{componentCatalog}
```

d) `{planningDir}/pde-pipeline-summary.md` — auxiliary file for root GEMINI.md @file import:
```
<!-- PDE-GENERATED | hash:{hash} | generated:{ts} -->
{pipelineStatus}
```

e) `{planningDir}/design/pde-design-summary.md` — auxiliary file for root GEMINI.md @file import:
```
<!-- PDE-GENERATED | hash:{hash} | generated:{ts} -->
{designTokens}

{componentCatalog}
```

- GEMINI.md @file imports MUST use `.md` extension only (no .json)
- Use relative paths from the GEMINI.md file's location

**8. Orchestrator function (`emitAll(cwd)`):**
- Resolve `planningDir = path.join(cwd, '.planning')`
- Resolve `projectRoot = cwd`
- Call `buildContextIR(planningDir)`
- Call each emitter, collect results
- Return summary object: `{ agentsMd, cursorRules, cursorrules, geminiMd, sourceHash, generatedAt }`

**9. CLI command function (`cmdContextSync(cwd, args, raw)`):**
- Call `emitAll(cwd)`
- Use `output()` from core.cjs to return results
- Handle `--editor` flag if present (filter to specific editor), otherwise emit all
- On error, use `error()` from core.cjs

**10. Exports:**
```javascript
module.exports = {
  buildContextIR,
  emitAll,
  emitAgentsMd,
  emitCursorRules,
  emitCursorrules,
  emitGeminiMd,
  computeSourceHash,
  cmdContextSync,
};
```
