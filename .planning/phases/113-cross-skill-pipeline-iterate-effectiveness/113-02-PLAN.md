Create bin/iterate-effectiveness-metric.cjs as a CJS Node.js script that measures the DOM quality delta between a pre-iterate and post-iterate wireframe pair.

**File structure (follow dom-metric.cjs pattern exactly):**

Line 1: #!/usr/bin/env node
Line 2: 'use strict';

JSDoc comment block:
- iterate-effectiveness-metric.cjs -- Iterate improvement delta metric.
- Measures the DOM quality improvement produced by one /pde:iterate cycle.
- Contract: exit 0 always, last line of stdout = numeric delta score.
- ITER-01: before/after screenshot capture (optional, via Playwright MCP)
- ITER-02: visual delta measurement (post_score - pre_score)
- ITER-04: outputs delta; convergence speed derived from JSONL history in report
- Usage: node bin/iterate-effectiveness-metric.cjs --fixture pre.html post.html
- --fixture: use a pre-existing wireframe pair (REQUIRED in Phase 113)

**Required imports (CJS pattern from dom-metric.cjs):**
- const path = require('path');
- const fs = require('fs');
- const { spawnSync } = require('child_process');

**Timeout guard (VIS-06 pattern from dom-metric.cjs):**
- TIMEOUT_MS = 45000 (45 seconds -- fixture mode is fast, but leave margin)
- setTimeout that writes '0\n' to stdout and calls process.exit(0) on timeout
- Store the timeoutId for clearTimeout later

**Argument parsing:**
- Parse process.argv.slice(2)
- Look for --fixture flag followed by two file paths (pre.html, post.html)
- If --fixture not found OR fewer than 2 paths after it: write '0\n' to stdout and exit 0 (graceful degradation, matching VIS-07 pattern)

**measureDomScore(htmlPath) helper function:**
- Calls spawnSync('node', [path.join(__dirname, 'dom-metric.cjs'), htmlPath], { encoding: 'utf-8', timeout: 15000 })
- If spawnSync returns status !== 0 or stdout is empty: return 0
- Parse the last line of stdout as parseFloat
- If NaN: return 0
- Return the parsed score

**captureScreenshot(htmlPath, label) helper function (ITER-01):**
- Try/catch wrapper -- failure must NOT prevent metric output
- Use require(path.join(__dirname, 'lib', 'mcp-bridge.cjs')) to get bridge
- Call bridge.call('playwright:screenshot', { filename: path.join(process.cwd(), '.planning', 'design', 'ux', 'wireframes', 'screenshots', label + '-' + path.basename(htmlPath, '.html') + '.png'), type: 'png' })
- On any error: write to stderr and continue (screenshot is optional enhancement)

**Main run() function (async):**
1. Extract prePath and postPath from --fixture args
2. Resolve paths: if not absolute, resolve relative to process.cwd()
3. Verify both files exist with fs.existsSync -- if either missing, write '0\n' and exit 0
4. Measure PRE score: const preScore = measureDomScore(prePath)
5. Attempt pre-iterate screenshot: captureScreenshot(prePath, 'pre-iterate')  (ITER-01)
6. Measure POST score: const postScore = measureDomScore(postPath)
7. Attempt post-iterate screenshot: captureScreenshot(postPath, 'post-iterate')  (ITER-01)
8. Compute delta: const delta = postScore - preScore  (ITER-02)
9. clearTimeout(timeoutId)
10. Write delta as string to stdout: process.stdout.write(String(delta) + '\n')
11. process.exit(0)

**Error handling:**
- Wrap entire run() in try/catch
- Catch block: clearTimeout(timeoutId), write '0\n' to stdout, exit 0
- This matches the VIS-07 degradation pattern from all existing metric scripts

**Call run() at module level (bottom of file)**

**DO NOT:**
- Import any npm packages (zero-dep constraint)
- Use ESM syntax (bin/ uses CJS only)
- Invoke /pde:iterate live (Phase 113 uses fixture mode only; live mode documented for future use)
- Use pixel comparison (out of scope per REQUIREMENTS.md)
