       - CRITICAL: @gradio/client is ESM-only. Use `const { Client } = await import('@gradio/client');` inside async functions (per Pitfall 6).
       - Define SPACE_CHAIN constant array: `['stabilityai/stable-fast-3d', 'TencentARC/InstantMesh']` (per Pitfall 1 — fallback chain for HF Space downtime)
       - `async function convert3D({ imageBuffer, slug = 'model', assetsDir })`:
         a. Check `process.env.HF_TOKEN` — if missing, throw Error: `'Set HF_TOKEN environment variable: https://huggingface.co/settings/tokens'` (per Pitfall 5)
         b. Preprocess image with sharp: resize to 512x512 PNG, get Buffer
         c. Loop through SPACE_CHAIN, for each space:
            - `const { Client } = await import('@gradio/client')`
            - `const app = await Client.connect(space, { hf_token: process.env.HF_TOKEN })`
            - Create Blob from imageBuffer: `new Blob([imageBuffer], { type: 'image/png' })`
            - Try `app.predict('/run', [imageBlob])` — if 404/EndpointNotFound, try `/predict` and `/generate` as fallback route names (per Pitfall 2)
            - Extract GLB data from result.data (may be file URL or Blob)
            - If file URL: fetch it to get Buffer. If Blob: convert via arrayBuffer()
            - On success: break loop
            - On failure: console.warn and continue to next space
         d. If all spaces fail: throw Error with message listing failed spaces and suggesting local Python fallback
         e. Write raw GLB to tmpfile, run optimizeGLB({ inputPath: tmpPath, outputPath: optimizedPath })
         f. Read optimized GLB buffer, run inspectGLB for vertex_count
         g. Compute sha256 of original imageBuffer for input_hash
         h. Call save3DAsset with meta: `{ source_model: successfulSpaceName, input_type: 'image', input_hash, file_size, vertex_count, slug }`
         i. Return `{ glbPath, metaPath, meta }`
       - Export: `module.exports = { convert3D, SPACE_CHAIN }`

    2. Create `bin/lib/3d-pipeline/generate.cjs` (per TRD-01):
       - `async function generate3D({ prompt, slug = 'model', assetsDir })`:
         a. Check `process.env.HF_TOKEN` — same check as convert.cjs
         b. Step 1 — text-to-image via @huggingface/inference:
            - `const { InferenceClient } = require('@huggingface/inference')`
            - `const client = new InferenceClient(process.env.HF_TOKEN)`
            - `const blob = await client.textToImage({ model: 'black-forest-labs/FLUX.1-schnell', inputs: prompt, parameters: { num_inference_steps: 4 } })`
            - Convert Blob to Buffer: `Buffer.from(await blob.arrayBuffer())`
         c. Step 2 — image-to-3D via convert3D:
            - `const { convert3D } = require('./convert.cjs')`
            - `const result = await convert3D({ imageBuffer, slug, assetsDir })`
            - Override result.meta.input_type to 'text' and add `prompt` field to meta
         d. Return result with updated meta
       - Export: `module.exports = { generate3D }`

    Both modules: 'use strict', CJS pattern, require for CJS deps, dynamic import() only for @gradio/client.
