       ### Subcommand: watch URL [--json-diff]

       **Purpose:** Track changes on a competitor or dependency page. First call establishes a baseline snapshot. Subsequent calls produce a semantic markdown diff showing what changed.

       **Step 1: Credit guard check** — Same pattern as scrape subcommand (copy the probe block verbatim).

       **Step 2: Acquire concurrency semaphore** — Same pattern as scrape subcommand.

       **Step 3: Check for existing baseline**
       ```bash
       node -e "
       const c = require('./bin/lib/firecrawl-cache.cjs');
       const slug = c.slugifyUrl('URL_FROM_ARGS');
       const baseline = c.readSnapshot(slug);
       console.log(JSON.stringify({ hasBaseline: !!baseline, slug }));
       "
       ```
       Parse the JSON result. Branch on hasBaseline.

       **Step 4a: If hasBaseline is FALSE (first call) — establish baseline**
       - Call mcp__firecrawl__firecrawl_scrape with url=URL, formats=["markdown"]
       - Parse response: extract response.markdown
       - Call writeSnapshot(URL, response.markdown) to save baseline
       - Display to user: "Baseline snapshot saved for {URL}. Slug: {slug}. Run `/pde:firecrawl watch {URL}` again to see changes."
       - Do NOT use changeTracking on first call (Pitfall 3)

       **Step 4b: If hasBaseline is TRUE (subsequent call) — scrape with changeTracking**
       - CRITICAL: formats array MUST include both "markdown" AND "changeTracking" (Pitfall 1: silent empty diffs if markdown omitted)
       - Default (no --json-diff flag): `formats: ["markdown", "changeTracking"]` — git-diff mode, FREE
       - With --json-diff flag: `formats: ["markdown", { type: "changeTracking", modes: ["json"] }]` — 5 credits/page EXTRA, display cost warning before proceeding
       - Call mcp__firecrawl__firecrawl_scrape with the appropriate formats

       **Step 5: Process changeTracking response**
       Parse response.changeTracking:
       - If changeStatus === "new": Display "First tracked scrape — no previous data on Firecrawl's side. Baseline saved locally."
       - If changeStatus === "same": Display "No changes detected since {previousScrapeAt}."
       - If changeStatus === "changed":
         - Compute linesChanged: `diff.text.split('\n').filter(l => (l.startsWith('+') || l.startsWith('-')) && !l.startsWith('+++') && !l.startsWith('---')).length`
         - Call writeDiff(URL, diff.text, linesChanged, previousScrapeAt)
         - Update baseline: call writeSnapshot(URL, response.markdown) to store the latest content
         - Display summary: "Changes detected on {URL}: {linesChanged} lines changed since {previousScrapeAt}. Diff saved to {diffPath}."
       - If changeStatus === "removed": Display "Page appears to have been removed since {previousScrapeAt}."

       **Step 6: Release semaphore** — Same pattern as scrape subcommand.

       **Step 7: Display result summary** — Show the diff file path if changes were detected. Do NOT inject diff content inline (per success criteria).

    3. Ensure the --json-diff flag section includes a clear cost warning: "Warning: JSON diff mode costs 5 additional credits per page. Git-diff mode (default) is free."
