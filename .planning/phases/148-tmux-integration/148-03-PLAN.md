<!-- Enriched NDJSON line format written by TmuxFanout (Plan 01) -->
Each line in pde-multi-session.ndjson is a JSON object with at minimum:
```json
{
  "event_type": "subagent_start",
  "ts": "2026-03-27T12:00:00.000Z",
  "agent_type": "planner",
  "_pde_session_id": "p148-1-abc12345",
  "_pde_session_source": "L",
  "_pde_color_index": 0
}
```

Fields:
- `_pde_session_id`: full session ID string (format: `p{phase}-{plan}-{8hex}`)
- `_pde_session_source`: `"L"` (local) or `"R"` (remote ssh/managed)
- `_pde_color_index`: integer 0-5, stable per session

ANSI 256-color palette mapping:
| Index | Color   | Escape code        |
|-------|---------|--------------------|
| 0     | blue    | `\033[38;5;33m`    |
| 1     | green   | `\033[38;5;82m`    |
| 2     | violet  | `\033[38;5;129m`   |
| 3     | amber   | `\033[38;5;214m`   |
| 4     | rose    | `\033[38;5;197m`   |
| 5     | cyan    | `\033[38;5;51m`    |
Reset: `\033[0m`

<!-- Filter file from tmux-cycle-session.cjs (Plan 02) -->
$TMPDIR/pde-tmux-filter.txt contains either "all" or a session ID string.
