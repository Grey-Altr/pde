    - recalculateFromArtifacts reads all `.planning/phases/*/COMPLETED-REQS.md` files, unions requirement IDs, marks them complete in REQUIREMENTS.md
    - recalculateFromArtifacts returns `{ phasesCompleted, requirementsCompleted, updated: true }` summary

  <action>
    **Step 1: Create packages/dispatcher/lib/merge.cjs** (per D-11, D-12, D-13)
    Follow RESEARCH.md Pattern 2 reference implementation with additions:

    `mergeSession(projectRoot, sessionId)`:
    - Branch name: `pde/session/<sessionId>`
    - Try `git merge <branch> --no-edit` via execFileSync
    - On success: return `{ ok: true, conflicts: [] }`
    - On failure (catch): run `git diff --name-only --diff-filter=U` to get conflicted files
    - Split conflicts into `planningConflicts` (start with `.planning/`) and `sourceConflicts`
    - For each planningConflict: `git checkout --ours -- <file>` then `git add -- <file>`
    - For `.planning/agent-memory/` conflicts specifically (per D-13): instead of checkout --ours, read both versions, concatenate content, write merged, `git add`
    - If no sourceConflicts remain: `git commit --no-edit`, return `{ ok: true, conflicts: planningConflicts, autoResolved: planningConflicts }`
    - If sourceConflicts exist: `git merge --abort`, return `{ ok: false, conflicts: sourceConflicts, needsHuman: true }`

    `recalculateFromArtifacts(projectRoot)`:
    - Use `fs.readdirSync` to find all phase directories matching pattern `NNN-*` in `.planning/phases/`
    - For each phase dir, check if `COMPLETE.json` exists. If yes, parse it (contains `{ session_id, exit_code, phase, plan, ... }`)
    - Count phases with COMPLETE.json where `exit_code === 0` as completed
    - Read `.planning/STATE.md` via `fs.readFileSync`, update frontmatter fields:
      - `progress.completed_phases` = count of completed phases
      - `progress.percent` = Math.round((completed / total) * 100)
      - `status` = all complete ? "complete" : "in_progress"
    - Write STATE.md back
    - Read `.planning/ROADMAP.md`, for each completed phase, change `- [ ] **Phase N:` to `- [x] **Phase N:`
    - Write ROADMAP.md back
    - For each phase dir, check if `COMPLETED-REQS.md` exists. Parse YAML frontmatter to extract `requirements` array
    - Union all requirement IDs from all COMPLETED-REQS.md files
    - Read `.planning/REQUIREMENTS.md`, for each req ID: change `- [ ] **<ID>**` to `- [x] **<ID>**` and table status from `Pending` to `Complete`
    - Write REQUIREMENTS.md back
    - Return `{ phasesCompleted, requirementsCompleted: [...ids], updated: true }`
