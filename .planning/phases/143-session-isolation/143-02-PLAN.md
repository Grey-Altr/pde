<objective>
Implement orphan detection and nuclear reset for session worktrees.

Purpose: Crashed or abandoned sessions leave worktrees behind. Without orphan detection, these accumulate silently and waste disk space. Without nuclear reset, there is no recovery path when things go wrong. Both are safety nets for the session isolation system.

Output: packages/dispatcher/lib/orphan.cjs with detectOrphans and resetAllSessions, plus passing tests.
</objective>

    - resetAllSessions returns `{ removed: N }` with count of sessions cleaned
    - resetAllSessions on empty state (no sessions) returns `{ removed: 0 }` without error

  <action>
    **Step 1: Create packages/dispatcher/lib/orphan.cjs** (per D-15, D-16, D-17, D-20)
    Follow RESEARCH.md Pattern 3 reference implementation:

    `isProcessAlive(pid)`:
    - `try { process.kill(pid, 0); return true; } catch (e) { return e.code !== 'ESRCH'; }`
    - ESRCH = no such process (dead). EPERM = exists but no permission (alive).

    `detectOrphans(projectRoot, sessionRegistry)`:
    - `sessionRegistry` is a Map<sessionId, { pid, status, ... }> or null/undefined
    - Call `listSessionWorktrees(projectRoot)` from worktree.cjs
    - For each entry, extract sessionId from `entry.branch.replace('refs/heads/pde/session/', '')`
    - Look up sessionId in registry. If no entry or entry's PID is dead: push to orphans array
    - Orphan object shape: `{ sessionId, worktreePath: entry.worktree, branch: entry.branch.replace('refs/heads/', ''), status: 'dead_process' | 'unregistered' }`
    - Return orphans array (caller presents adopt/kill/ignore per D-16)

    `resetAllSessions(projectRoot)` (per D-17):
    - Call `listSessionWorktrees(projectRoot)`
    - For each session worktree:
      - Extract sessionId from branch
      - Call `removeWorktree(projectRoot, sessionId, { force: true })` — force remove even if dirty
      - Call `deleteBranch(projectRoot, entry.branch.replace('refs/heads/', ''), { force: true })` — `-D` to skip merge check
    - Catch errors per-session (one failure should not prevent cleaning others)
    - Call `execFileSync('git', ['worktree', 'prune'])` at end to clean up admin files
    - Return `{ removed: count }`
