## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inner padding, divider margins |
| sm | 8px | Inline element spacing, compact card internal gaps |
| md | 16px | Default card padding, list item spacing, form field gaps |
| lg | 24px | Card-to-card gap in session list, section padding |
| xl | 32px | Page horizontal padding (mobile), major layout gaps |
| 2xl | 48px | Top-of-page breathing room, section breaks |
| 3xl | 64px | Reserved for page-level spacing (desktop only) |

Exceptions:
- Touch targets (status badge tap area, session card tap): minimum 44px height per MON-05 requirement. Cards are full-width and naturally exceed this; badges must have minimum 44px hit area on mobile.
- Mini event log rows: 36px height acceptable (read-only, not interactive).

## Color

Dark mode is the default rendering context. All values are dark mode tokens.

**Primary focal point:** active session status badge (green pulse ring) in the session list card.

| Role | Tailwind Token | Dark Mode Hex (approx) | Usage |
|------|---------------|------------------------|-------|
| Dominant (60%) | `background` | #09090b (zinc-950) | Page background, scrollable areas |
| Secondary (30%) | `card` | #18181b (zinc-900) | Session cards, status card surface, nav bar background |
| Accent (10%) | `primary` | #fafafa (zinc-50) | Primary CTA button, active session badge ring |
| Destructive | `destructive` | #ef4444 (red-500) | Error status badge, error event type in log |

Semantic status colors (not general accent — scoped to badge states only):

| Badge State | Color Token | Approximate Hex | Usage |
|-------------|-------------|-----------------|-------|
| active | green-500 | #22c55e | Active session badge background; animated pulse ring |
| idle | amber-500 | #f59e0b | Idle session badge background |
| error | red-500 | #ef4444 | Error session badge background |
| complete | zinc-500 | #71717a | Complete session badge background (muted/gray) |

Accent reserved for: primary CTA buttons only, active session pulse ring animation. NOT for general links, borders, hover states, or decorative elements.

Light mode: shadcn/ui tokens automatically invert — no separate light mode color specification needed. The dark mode default is enforced via `next-themes` with `defaultTheme="dark"`.

## Interaction Contract

### Session List Page (`/`)

| Interaction | Behavior |
|-------------|----------|
| Page load (no sessions) | Render empty state (see Copywriting Contract) |
| Page load (sessions exist) | Render skeleton cards while data loads, then fade in session cards |
| Session card tap/click | Navigate to `/sessions/{id}` — full-width card is the tap target (no separate "View" button) |
| Real-time update | Cards reorder by last_event_ts score — active sessions bubble to top; no page reload |
| Status badge | Static label + colored dot; active state adds CSS pulse animation (`animate-pulse`) on the dot |

### Session Detail Page (`/sessions/[id]`)

| Interaction | Behavior |
|-------------|----------|
| Page load | Render skeleton for status card while HGETALL fetches, then reveal |
| Live event arrival | Append to mini event log; update phase/plan/elapsed fields in-place without full re-render |
| SSE connection active | No user-visible indicator (silent when healthy) |
| SSE missed heartbeat (>30s) | Show inline connection badge: "Reconnecting..." in amber, auto-dismiss when reconnected |
| Polling fallback active | Show inline connection badge: "Live (polling)" in zinc/muted — user can see they're on fallback |
| Connection restored | Replace fallback badge with no badge (healthy state is silent) |
| No events in 60s (idle) | Status badge on this page transitions to idle/amber — no user action required |

### Sign-In Page (`/sign-in`)

| Interaction | Behavior |
|-------------|----------|
| Unauthenticated access | Clerk middleware redirects to `/sign-in` automatically |
| Sign-in | Clerk-hosted component handles UI — no custom interaction contract needed |

## Layout Contract

### Mobile (default — phone-first per ROADMAP.md Phase 136 MON-05)

- Single column, full viewport width
- Horizontal padding: 16px (md) left and right
- Session list: vertical stack, cards full-width, 12px gap between cards
- Session detail: single column, status card full-width, mini log below
- Navigation: none in Phase 135 (scaffold only — bottom tabs come in Phase 138 PWA)

### Desktop (secondary)

- Max content width: 640px, centered
- Horizontal padding: 32px (xl)
- Same single-column stack — no sidebar, no grid

### Breakpoints

| Breakpoint | Width | Behavior |
|------------|-------|---------|
| mobile | < 640px (sm) | Phone-first layout, 16px padding |
| tablet+ | >= 640px | Centered column, max-w-screen-sm, 32px padding |
