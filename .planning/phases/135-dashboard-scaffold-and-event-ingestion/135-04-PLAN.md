    1. dashboard/lib/queries.ts -- Server-side Redis query helpers:

    Export interface SessionListItem with fields: id (string), status (SessionStatus), phase (string), plan (string), lastEventType (string), lastEventTs (number), startedAt (number).

    Export async function getSessions(): Promise of SessionListItem array:
    - Get session IDs ordered by last event time descending: redis.zrange('pde:default:sessions', 0, -1, { rev: true })
    - If empty, return empty array
    - Fetch metadata for each session via redis.pipeline(), calling p.hgetall('pde:default:session:' + id) for each
    - Map results to SessionListItem objects, deriving status via deriveStatus(lastEventType, lastEventTs)

    Export async function getSessionMeta(sessionId: string): Promise of SessionListItem or null:
    - redis.hgetall('pde:default:session:' + sessionId)
    - Return null if no data
    - Derive status, return SessionListItem

    Export async function getRecentEvents(sessionId: string, count = 10): Promise of unknown array:
    - redis.zrange('pde:default:events:' + sessionId, -count, -1)
    - Parse each JSON string member, reverse for newest-first
    - Return array
