2. Create `bin/lib/cli-anything/parsers/graphql.cjs` with these key functions:

- `INTROSPECTION_QUERY` constant: the standard GraphQL introspection query string that fetches `__schema { queryType { name } mutationType { name } types { name kind description fields(includeDeprecated: false) { name description args { name description type { name kind ofType { name kind } } } type { name kind ofType { name kind ofType { name kind } } } } } }`

- `gqlTypeToJsonSchemaType(gqlType)`: maps GraphQL SCALAR names to JSON Schema types — String/ID to 'string', Int/Float to 'number', Boolean to 'boolean', default 'string'. Handles nested ofType for NON_NULL wrappers.

- `argsToJsonSchema(args)`: converts array of GraphQL field args to `{ type: 'object', properties: { argName: { type: '...', description: '...' } } }`. Returns empty properties object if no args.

- `gqlTypeToJsonSchema(gqlType)`: converts GraphQL return type to JSON Schema — LIST becomes `{ type: 'array', items: ... }`, OBJECT becomes `{ type: 'object', description: typeName }`, SCALAR maps via gqlTypeToJsonSchemaType.

- `parseIntrospectionResult(introspectionData)`: takes `{ __schema: {...} }`, finds root type names from queryType/mutationType, filters schema.types to only root types, flatMaps their fields to capabilities. Each capability: `{ name: field.name, description: field.description || '', inputSchema: argsToJsonSchema(field.args), outputSchema: gqlTypeToJsonSchema(field.type), method: null, path: null, extensions: { parentType: type.name, returnType: field.type } }`.

- `parse(source, content)`: if source starts with http/https, POST introspection query via fetch, parse response, call parseIntrospectionResult. If content is a string (SDL file), do basic regex extraction of Query/Mutation field names from `type Query { ... }` blocks. Throw on unrecognized source.

All functions follow `'use strict'` CJS pattern with `module.exports = { parse, parseIntrospectionResult, INTROSPECTION_QUERY, argsToJsonSchema, gqlTypeToJsonSchema }`.
