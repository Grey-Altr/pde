   **pushPlanningState(projectRoot, branch, _git):**
   - Instantiate: `const git = _git || simpleGit(projectRoot);`
   - Push session branch to origin: `await git.push('origin', branch);`
   - Wrap in try/catch, return `{ ok: true }` on success, `{ ok: false, error: err.message }` on failure.
   - Do NOT stage or commit — per CONTEXT.md "worktree branch already has .planning/ committed".

   **fetchPlanningState(projectRoot, branch, _git):**
   - Instantiate: `const git = _git || simpleGit(projectRoot);`
   - Fetch: `await git.fetch('origin', branch);`
   - Return `{ ok: true }` on success, `{ ok: false, error: err.message }` on failure.

   **mergePlanningFromCloud(projectRoot, branch, _git):**
   - Instantiate: `const git = _git || simpleGit(projectRoot);`
   - Attempt merge: `await git.merge(['origin/' + branch, '--no-edit']);`
   - On success: return `{ ok: true, conflicts: [], autoResolved: [] }`
   - On merge error (catch block):
     a. Detect conflicts with `execFileSync('git', ['diff', '--name-only', '--diff-filter=U'], { cwd: projectRoot, encoding: 'utf8', stdio: 'pipe' })` — split by newline, filter empty.
     b. Separate `planningConflicts` (startsWith `.planning/`) from `sourceConflicts`.
     c. If sourceConflicts.length > 0: `execFileSync('git', ['merge', '--abort'], ...)` and return `{ ok: false, conflicts: sourceConflicts, needsHuman: true }`.
     d. For each planningConflict: determine strategy — if file is in CLOUD_THEIRS use `'--theirs'`, otherwise `'--ours'`. Run `execFileSync('git', ['checkout', strategy, '--', file], ...)` then `execFileSync('git', ['add', '--', file], ...)`.
     e. Finalize: `execFileSync('git', ['commit', '--no-edit'], { cwd: projectRoot, stdio: 'pipe' })`.
     f. Return `{ ok: true, conflicts: planningConflicts, autoResolved: planningConflicts }`.

   **module.exports:** `{ pushPlanningState, fetchPlanningState, mergePlanningFromCloud }`
