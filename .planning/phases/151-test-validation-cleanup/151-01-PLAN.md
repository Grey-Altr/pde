    analyzeDag: vi.fn(async () => ({ parallelizable: [], unsafe: [] })),

- `analyzeDag` returns `{ parallelizable: [], unsafe: [] }` because coordinator caches via `this._dag = await this._analyzeDag(root)` and later accesses `.overlapping`. Empty arrays are valid and non-blocking.
- `routeSession` returns `'local'` because coordinator branches on `backend === 'ssh'` for remote execution. Returning `'local'` routes to the existing `spawnSession` stub.

Do NOT add stubs for `checkFileOverlap`, `summarizeFailure`, or `triageConflicts` — `checkFileOverlap` is synchronous and handles empty temp directories correctly; `summarizeFailure` and `triageConflicts` are only called in `_handleExit` exit handlers, not in `dispatchWave`.
