**Part A: Fix aggregator.cjs — Docker uses TailCursor, not RemoteAggregator**

This is the key architectural decision from the planning context. Docker writes NDJSON to local `/tmp/pde-session-{id}.ndjson`, so TailCursor works. RemoteAggregator is reserved for cloud sessions (Phase 193) which push events over HTTP and do NOT write local files.

In `packages/dispatcher/lib/aggregator.cjs`, change the `watch()` method (line 67):

FROM:
```javascript
const isRemote = sessionType === 'cloud' || sessionType === 'docker';
```

TO:
```javascript
const isRemote = sessionType === 'cloud';
```

This means `watch(id, 'docker')` now uses TailCursor (local file tailing), and only `watch(id, 'cloud')` uses RemoteAggregator. This is correct because:
- Docker: container writes NDJSON to local `/tmp/` file -> TailCursor tails it -> works
- Cloud (Phase 193): no local NDJSON file -> RemoteAggregator receives HTTP push -> correct
