**Step 2: Implement spawnDockerSession in packages/cloud-adapter/index.cjs**

Replace the stub with the full implementation. The function signature:

```javascript
function spawnDockerSession(opts)
```

opts shape (mirrors spawnRemoteSession):
- `sessionId` — PDE session ID (e.g. "p191-1-abc12345")
- `relayId` — UUID relay ID for NDJSON correlation
- `phase` — Phase number
- `plan` — Plan number
- `worktreePath` — Absolute path to git worktree directory
- `pluginDir` — PDE plugin directory path
- `dockerConfig` — `{ image, memory, cpus, failure_cleanup_ms }` from dispatch config
- `onLine(sessionId, parsedEvent)` — callback for each NDJSON line
- `onExit(sessionId, exitCode)` — callback on container exit
- `_deps` — `{ Dockerode }` for DI in tests

Implementation structure (async IIFE + sync kill handle):

1. Outer scope: `let containerInstance = null;`
2. Compute `effectiveSessionId = opts.relayId || opts.sessionId`
3. Compute `ndjsonPath = path.join(os.tmpdir(), 'pde-session-' + effectiveSessionId + '.ndjson')`
4. Async IIFE:
   a. `const docker = new DockerodeClass()`
   b. `createContainer({...})` with these exact values:
      - `Image`: `dockerConfig.image || 'pde-session:latest'`
      - `WorkingDir`: `'/workspace'`
      - `Env`: array of `'KEY=value'` strings:
        - `'CLAUDECODE='` (empty — CRITICAL)
        - `'PDE_SESSION_ID=' + effectiveSessionId`
        - `'PDE_PHASE=' + opts.phase`
        - `'PDE_PLAN=' + opts.plan`
        - `'PDE_BACKEND=docker'`
        - `'PDE_SESSION_START=' + new Date().toISOString()`
        - Conditionally: `'PDE_REMOTE=' + ingestUrl` (if `process.env.PDE_REMOTE`)
        - Conditionally: `'PDE_RELAY_TOKEN=' + relayToken` (if `process.env.PDE_RELAY_TOKEN`)
      - `OpenStdin`: `false` (CRITICAL — prevents hang)
      - `Tty`: `false` (CRITICAL — prevents NDJSON corruption)
      - `Labels`: `{ 'pde-session': opts.sessionId }`
      - `HostConfig.Binds`: `[opts.worktreePath + ':/workspace']`
      - `HostConfig.AutoRemove`: `true`
      - `HostConfig.Memory`: only if `dockerConfig.memory` — call `parseMemory(dockerConfig.memory)` helper
      - `HostConfig.NanoCpus`: only if `dockerConfig.cpus` — `Math.floor(dockerConfig.cpus * 1e9)`
      - `Cmd`: `['claude', '--print', '--bare', '--output-format', 'stream-json', '--verbose', '--dangerously-skip-permissions', '--plugin-dir', opts.pluginDir || '/root/.claude/pde', '--append-system-prompt', 'You are a PDE executor agent running in a worktree. Operate in autonomous mode. Auto-approve all checkpoints. Do not ask questions.', 'Execute phase ' + opts.phase + ', plan ' + opts.plan + '. Run /gsd:execute-plan ' + opts.phase + ' ' + opts.plan + '.']`
   c. `containerInstance = container;`
   d. `await container.start();`
   e. Open NDJSON write stream: `const ndjsonStream = fs.createWriteStream(ndjsonPath, { flags: 'a' });`
   f. Stream logs + wait concurrently (wrap in Promise):
      - `container.logs({ follow: true, stdout: true, stderr: true, timestamps: false }, cb)`
      - In cb: demux with `container.modem.demuxStream(logStream, stdoutPass, stderrPass)`
      - readline on stdoutPass: parse JSON, call `opts.onLine(opts.sessionId, parsed)`, write to ndjsonStream
      - stderrPass.on('data'): call `opts.onLine(opts.sessionId, { type: 'system', subtype: 'stderr', message: msg })`
      - `container.wait().then(data => { logStream.destroy(); rl.close(); ndjsonStream.end(); resolve(data); })`
   g. Extract exitCode: `waitResult.StatusCode != null ? waitResult.StatusCode : 1`
   h. If exitCode !== 0: set `setTimeout(() => { try { containerInstance && containerInstance.kill(); } catch (_) {} }, cleanupMs).unref()` where cleanupMs defaults to 600_000
   i. Call `opts.onExit(opts.sessionId, exitCode)`
5. Async IIFE .catch: `opts.onLine(opts.sessionId, { type: 'system', subtype: 'docker_error', message: err.message }); opts.onExit(opts.sessionId, 1);`
6. Synchronous return: `{ kill: () => { if (containerInstance) { try { containerInstance.kill(); } catch (_) {} } } }`

Add a `parseMemory(val)` helper that converts string like '512m' or '2g' to bytes (number).

Export: `module.exports = { spawnDockerSession };`
