       ```
       url.replace(/^https?:\/\//, '').replace(/[\/\?#&=:@]/g, '-').replace(/\./g, '-').replace(/-+/g, '-').replace(/^-|-$/g, '').toLowerCase().slice(0, 200)
       ```

    3. `resolveManifestPath(projectRoot)` -- returns `path.join(projectRoot || process.cwd(), '.planning', 'sources-manifest.json')`

       - Compute slug via slugifyUrl

       - If file exists and !opts.force: return `{ slug, path, cached: true, written: false }`
       - Else: ensureCacheDir, writeFileSync, update manifest atomically with { slug, url, type: metadata.type || 'scrape', format: 'markdown', word_count, scraped_at, cached_path, added_by: metadata.added_by || 'cache-module' }
       - Return `{ slug, path, cached: false, written: true }`

    8. `readSource(slug, projectRoot)` -- read `scrapes/{slug}.md`, return content or null

    9. `writeCrawl(url, pages, metadata = {}, opts = {}, projectRoot)`:

       - Write each page as `{pageIndex}-{pageSlug}.md` inside the directory
       - Update manifest with type: 'crawl', page_count, total_word_count

    10. `writeSnapshot(url, content, projectRoot)` -- write to `snapshots/{slug}.md`

    11. `readSnapshot(slug, projectRoot)` -- read `snapshots/{slug}.md`, return content or null
