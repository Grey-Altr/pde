  <action>
    Create commands/source.md with YAML frontmatter containing:
    - name: pde:source
    - description: Add and manage source material from web URLs via Firecrawl scraping
    - argument-hint: "add URL [--force] [--type scrape|crawl] | list | show SLUG"
    - allowed-tools: Read, Write, Edit, Bash, Glob, Grep, mcp__firecrawl__firecrawl_scrape, mcp__firecrawl__firecrawl_search, mcp__firecrawl__firecrawl_crawl, WebFetch

    The command body should:
    1. Parse $ARGUMENTS for subcommand: `add`, `list`, `show`
    2. For `add URL`: follow @workflows/source.md
    3. For `list`: read .planning/sources-manifest.json via `node -e "const c = require('./bin/lib/firecrawl-cache.cjs'); const m = c.readManifest(); console.log(JSON.stringify(m.sources, null, 2))"` and format as table
    4. For `show SLUG`: read cached content via readSource and display

    Create workflows/source.md with the ingestion pipeline:

    Step 1 - Validate Input:
    - Parse URL from arguments
    - Validate URL format (must start with http:// or https://)
    - Parse --force flag
    - Parse --type flag (default: scrape)

    Step 2 - Check Cache (Idempotent):
    - Compute slug: `node -e "const c = require('./bin/lib/firecrawl-cache.cjs'); console.log(c.slugifyUrl('THE_URL'))"`
    - Check if already cached: `node -e "const c = require('./bin/lib/firecrawl-cache.cjs'); const r = c.readSource('THE_SLUG'); console.log(r ? 'CACHED' : 'MISS')"`
    - If CACHED and no --force flag: display cached content location and exit early
    - If CACHED and --force: continue to re-scrape

    Step 3 - Probe Firecrawl Availability:
    - Check if Firecrawl is available by running: `node -e "const m = require('./bin/lib/mcp-bridge.cjs'); const r = m.checkFirecrawlCredits(); console.log(JSON.stringify(r))"`
    - If credits exhausted or unavailable: fall back to WebFetch for the URL, then write result through cache module
    - If available: proceed with Firecrawl MCP tool

    Step 4 - Scrape/Crawl via Firecrawl:
    - For type=scrape (default): Call `mcp__firecrawl__firecrawl_scrape` with `{ url: THE_URL, formats: ["markdown"], onlyMainContent: true }`
    - For type=crawl: Call `mcp__firecrawl__firecrawl_crawl` with `{ url: THE_URL, limit: 50, scrapeOptions: { formats: ["markdown"], onlyMainContent: true } }`
    - After scrape: call `node -e "const m = require('./bin/lib/mcp-bridge.cjs'); m.incrementFirecrawlUsage(1)"` to track credit usage

    Step 5 - Write to Cache:
    - For scrape: `node -e "const c = require('./bin/lib/firecrawl-cache.cjs'); const r = c.writeSource('THE_URL', CONTENT, { type: 'scrape', added_by: 'source-add' }, { force: FORCE_FLAG }); console.log(JSON.stringify(r))"`
    - For crawl: `node -e "const c = require('./bin/lib/firecrawl-cache.cjs'); const r = c.writeCrawl('THE_URL', PAGES_ARRAY, { added_by: 'source-add' }, { force: FORCE_FLAG }); console.log(JSON.stringify(r))"`

    Step 6 - Confirm:
    - Display: source added, slug, cached path, word count
    - Show manifest entry count

    Fallback path (WebFetch when Firecrawl unavailable):
    - Use WebFetch tool to fetch URL content
    - Write through same cache module (content quality may be lower for JS-rendered sites)
    - Note in output that content was fetched via WebFetch fallback

    The workflow must reference firecrawl-cache.cjs for ALL disk I/O -- never write directly to .planning/research/firecrawl-cache/.
