  <action>
Create bin/lib/app-discovery.cjs as a CJS module with 'use strict' directive. Follow the exact code patterns from 171-RESEARCH.md (Patterns 1-4).

**Exports (via module.exports):**
- probeBinary(appDef, _fns) - Five-tier waterfall probe. Uses spawnSync with argument arrays (NEVER shell strings). Tiers: (1) env var, (2) which/where.exe, (3) pip module python3 -c importlib, (4) mdfind + plutil on darwin, (5) well-known paths with ~ expansion. Returns {tier, path, source} or null.
- resolveBinaryFromBundle(appBundlePath, {execFn, existsFn}) - macOS .app bundle resolution via plutil -convert json -o - Info.plist, reads CFBundleExecutable. Fallback: first file in Contents/MacOS/.
- probeDisplay(_fns) - Cross-platform display detection. darwin: ps aux grep WindowServer. linux: DISPLAY || WAYLAND_DISPLAY env check. win32: always true. Returns {available, method}.
- preprocessHelpText(rawText, _fns) - If rawText contains \x08, pipe through col -b via spawnSync({input: rawText}). If col fails (ENOENT), regex fallback rawText.replace(/.\x08/g, ''). Returns {text, parseQuality} where parseQuality is 'degraded' if backspaces were present, 'clean' otherwise.
- discoverApp(slug, _fns) - Looks up slug in APP_CATALOG, runs probeBinary, runs probeDisplay, returns discovery result with {slug, displayName, binaryPath, executionMode, probeSource, displayProbe, parseQuality}. If probe returns null, executionMode is 'mock' and binaryPath is null. If slug not in catalog, throws descriptive error.
- APP_CATALOG - Array of known app definitions for blender, gimp, inkscape. Each has: slug, displayName, cli, cliAlias (array), envVar, pipModule, bundleId, executionMode, headlessFlag, versionFlag, wellKnownPaths (keyed by platform). Use exact values from research:
  - blender: cli 'Blender', bundleId 'org.blenderfoundation.blender', executionMode 'headless', headlessFlag '--background', pipModule 'bpy'
  - gimp: cli 'gimp', bundleId 'org.gimp.gimp', executionMode 'headless', headlessFlag '-i', cliAlias ['gimp-3.0', 'gimp-2.10', 'gimp-2.99']
  - inkscape: cli 'inkscape', bundleId 'org.inkscape.Inkscape', executionMode 'headless', headlessFlag null

**Key implementation details:**
- All dependency-injectable via _fns parameter: existsFn, execFn, spawnFn, env, platform, homedir
- Tier 2: platform === 'win32' ? 'where.exe' : 'which'
- Tier 3: Only if appDef.pipModule is truthy
- Tier 4: Only if platform === 'darwin' AND appDef.bundleId is truthy
- Tier 4 mdfind result: filter for paths ending in .app, sort /Applications first, take [0]
- Tier 5: Expand ~ to homedir in well-known paths
- col -b: spawnSync('col', ['-b'], { input: rawText, encoding: 'utf8', timeout: 3000 })
- Regex fallback: rawText.replace(/.\x08/g, '')
- probeDisplay darwin: check ps aux output lines for 'WindowServer' excluding 'grep'
- All try/catch blocks around subprocess calls - failures fall through to next tier

**Anti-patterns to avoid (from research):**
- Do NOT use child_process.exec() - always spawnSync with argument arrays to prevent shell injection
- Do NOT hash binaries in this module - that is app-registry.cjs concern at approval time
- For Blender pip module (bpy), tier 3 finding bpy is supplemental only - continue probing tiers 4-5
