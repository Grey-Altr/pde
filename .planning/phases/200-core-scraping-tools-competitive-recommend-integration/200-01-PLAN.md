**Create workflows/firecrawl.md** — workflow prose with 6 subcommands:

**1. scrape URL [--force]** (SCR-01):
- Step 1: Credit guard — call probeFirecrawl() via node --input-type=module pattern. If unavailable, fall back to WebFetch.
- Step 2: Acquire semaphore via acquireFirecrawlSemaphore()
- Step 3: Call mcp__firecrawl__firecrawl_scrape with { url, onlyMainContent: true }
- Step 4: incrementFirecrawlUsage(1), release semaphore
- Step 5: Write to cache via writeSource(url, content, { type: 'scrape', added_by: 'pde:firecrawl scrape' })
- Display: "Scraped {url} -> cached at .planning/research/firecrawl-cache/scrapes/{slug}.md ({word_count} words)"

**2. search QUERY [--limit N] [--category CAT] [--since DATE]** (SCR-02, SCR-05):
- Step 1: Credit guard (same probe pattern)
- Step 2: Parse --limit (default 5), --category, --since from $ARGUMENTS
- Step 3: Call mcp__firecrawl__firecrawl_search with { query, limit, searchOptions: { category, after } }
- Step 4: incrementFirecrawlUsage(0.2)
- Step 5: If results contain scrapeOptions content (SCR-05), cache each via writeSource(resultUrl, resultContent, { type: 'search-scrape', added_by: 'pde:firecrawl search' })
- Display results as formatted table: Title, URL, Description

**3. map URL [--search FILTER] [--subdomains]** (SCR-03):
- Step 1: Credit guard
- Step 2: Call mcp__firecrawl__firecrawl_map with { url, search (if --search), includeSubdomains (if --subdomains) }
- Step 3: incrementFirecrawlUsage(0.5)
- Display URL list with count: "Found {N} URLs on {url}"

**4. extract URL --schema JSON** (SCR-04):
- Step 1: Parse --schema from $ARGUMENTS. If missing, display usage and halt.
- Step 2: Validate JSON parse of schema string. If invalid, display error and halt.
- Step 3: Credit guard
- Step 4: Call mcp__firecrawl__firecrawl_extract with { url, schema: parsedSchema }
- Step 5: incrementFirecrawlUsage(5) — extract costs 5 credits
- Display extracted JSON data
- CRITICAL: Schema is passed as parameter, NEVER hard-coded

**5. crawl URL [--limit N] [--max-depth N]** (CRL-01):
- Step 1: Parse --limit (default 50) and --max-depth (default 3)
- Step 2: Read FIRECRAWL_CRAWL_MAX_PAGES from env (default 50)
- Step 3: IF requested limit > cap: display "Warning: Requested {N} pages exceeds FIRECRAWL_CRAWL_MAX_PAGES cap ({cap}). Truncating to {cap}." SET effective_limit = cap
- Step 4: Credit guard
- Step 5: Call mcp__firecrawl__firecrawl_crawl with { url, limit: effective_limit, maxDepth }. Returns jobId.
- Step 6: Poll mcp__firecrawl__firecrawl_check_crawl_status every 5 seconds. Display "Crawled {N} pages so far..."
- Step 7: Timeout after 5 minutes — collect partial results, display warning
- Step 8: incrementFirecrawlUsage(page_count)
- Step 9: Write to cache via writeCrawl(url, pages, { added_by: 'pde:firecrawl crawl' })
- Display: "Crawled {N} pages from {url} -> cached at .planning/research/firecrawl-cache/crawls/{slug}/"

**6. Default (no subcommand or help):**
- Display usage with all subcommands and examples
