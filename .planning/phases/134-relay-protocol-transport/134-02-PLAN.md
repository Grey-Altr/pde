    **TailCursor class** (from Research Pattern 1):
    - Constructor: `(filePath, onLine)` where onLine is `callback(lineString)`
    - Properties: `this.filePath`, `this.onLine`, `this.position = 0`, `this.lastIno = null`, `this.remainder = ''`, `this._interval = null`
    - `start(intervalMs = 500)`: sets `this._interval = setInterval(() => this._poll(), intervalMs)`
    - `stop()`: clears interval, sets to null
    - `_poll()`:
      1. `fs.statSync(this.filePath)` — catch error and return (file not created yet)
      2. Rotation detection: if `stat.ino !== this.lastIno` and lastIno not null, reset position to 0 and clear remainder
      3. Update `this.lastIno = stat.ino`
      4. Truncation detection: if `stat.size < this.position`, reset position to 0 and clear remainder
      5. If `stat.size === this.position`, return (no new data)
      6. Calculate `length = stat.size - this.position`, allocate Buffer, `fs.openSync` with 'r', `fs.readSync` from position, `fs.closeSync` in finally
      7. Advance position by bytesRead
      8. Prepend `this.remainder`, split on `\n`, pop last element as new remainder, call `this.onLine(trimmed)` for each non-empty line

    **BatchQueue class** (from Research Pattern 2):
    - Constructor: `({ maxBatchSize = 50, flushIntervalMs = 2000, maxBufferSize = 1000, onFlush })`
    - `this.queue = []`, store all config and onFlush callback, `this._timer = null`
    - `push(event)`: if `queue.length >= maxBufferSize`, `queue.shift()` to drop oldest. Then push event. If `queue.length >= maxBatchSize`, call `this._flush()`
    - `start()`: `this._timer = setInterval(() => this._flush(), this.flushIntervalMs)`
    - `stop()`: clear timer, return `this._flush()` to flush remaining
    - `_flush()`: if queue empty return `Promise.resolve()`. Splice `maxBatchSize` events from front. Call `this.onFlush(batch).catch(() => {})` — swallow errors (circuit breaker handles)

    **CircuitBreaker class** (from Research Pattern 3):
    - States as module constants: `CB_CLOSED = 'CLOSED'`, `CB_OPEN = 'OPEN'`, `CB_HALF_OPEN = 'HALF_OPEN'`
    - Constructor: `({ failureThreshold = 5, cooldownMs = 30000 })`
    - Properties: `this.state = CB_CLOSED`, `this.failureCount = 0`, store config, `this._openedAt = null`
    - `canAttempt()`: CLOSED -> true. OPEN -> check `Date.now() - _openedAt >= cooldownMs`, if yes set HALF_OPEN return true, else false. HALF_OPEN -> true.
    - `recordSuccess()`: reset failureCount to 0, state to CLOSED
    - `recordFailure()`: increment failureCount. If HALF_OPEN, go to OPEN and set _openedAt. Else if failureCount >= threshold, go to OPEN and set _openedAt.

    **postEvents function** (from Research Pattern 4):
    - Signature: `function postEvents(url, bearerToken, events)`
    - Returns a Promise
    - Parse URL with `new URL(url)`
    - Choose `http` or `https` module based on `urlObj.protocol`
    - Options: hostname, port (443 for https, 80 for http, or urlObj.port), path: urlObj.pathname, method: 'POST'
    - Headers: `Content-Type: application/json`, `Content-Length: Buffer.byteLength(body)`, `Authorization: Bearer ${bearerToken}`
    - timeout: 10000ms
    - On response: `res.resume()` to drain body. Resolve if 2xx, reject otherwise.
    - On timeout: `req.destroy(new Error('request timeout'))`
    - On error: reject
    - `req.write(body); req.end()`

    **startRelay function:**
    - Signature: `function startRelay(sessionId, opts = {})`
    - opts: `{ ingestUrl, bearerToken, pollIntervalMs, batchSize, flushIntervalMs, failureThreshold, cooldownMs }`
    - Defaults: pollIntervalMs=500, batchSize=50, flushIntervalMs=2000, failureThreshold=5, cooldownMs=30000
    - Creates CircuitBreaker, BatchQueue (onFlush uses postEvents guarded by circuit breaker), TailCursor (onLine parses JSON and pushes to batch queue)
    - onLine callback: `JSON.parse(line)` in try/catch (skip unparseable lines), push parsed event to batch queue

    - Start tail cursor, start batch queue
    - Return `{ stop() }` that calls tail.stop() and batchQueue.stop()

    **stopRelay function:**

    - stopRelay calls `_activeRelay.stop()` if set, then nulls it
