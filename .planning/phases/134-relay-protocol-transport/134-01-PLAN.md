    **Step 2: Create `bin/lib/relay-protocol.cjs`.**
    This CJS module exports the wire protocol schema and envelope factory.

    Resolve zod: `require()` zod from `packages/pde-mcp-server/node_modules/zod` using explicit path resolution. Use `require(require.resolve('zod', { paths: [path.join(__dirname, '../../packages/pde-mcp-server')] }))`. If that fails, fall back to bare `require('zod')`.

    Define `WireEnvelopeSchema` as a zod object with these exact fields:
    - `seq`: z.number().int().nonnegative()
    - `session_id`: z.string().uuid()
    - `machine_id`: z.string().min(1)
    - `relay_ts`: z.string().datetime()
    - `approval_id`: z.string().uuid().nullable()
    - `schema_version`: z.string()
    - `ts`: z.string().datetime()
    - `event_type`: z.string().min(1)
    - `extensions`: z.record(z.unknown()).optional()
    Apply `.passthrough()` to allow additional PDE event fields.

    Module-level state:
    - `let _seq = 0;` (per-session monotonic counter)
    - `const _machineId = require('node:os').hostname();`

    Export `createEnvelope(sessionId, pdeEvent)`:
    - Takes a session UUID and a parsed PDE event object (from NDJSON line)
    - Returns `{ seq: _seq++, session_id: sessionId, machine_id: _machineId, relay_ts: new Date().toISOString(), approval_id: pdeEvent.approval_id || null, ...pdeEvent }`
    - Does NOT validate internally (caller validates if needed)

    Export `resetSequence()`: sets `_seq = 0`

    Export `WireEnvelopeSchema` for validation at call sites.

    Module exports: `module.exports = { WireEnvelopeSchema, createEnvelope, resetSequence };`
