### Findings

**INT-01 (Low): token_usage not in named EventLog filter tab**
- `token_usage` events appear under the `all` tab but not in any named tab (tools/agents/phases/errors)
- CostMeter is unaffected — `deriveCost` scans all events regardless of filter
- Affected: MON-03 (cosmetic — user cannot isolate token events by filter)

**INT-02 (Info): deriveProgress conditional on workflow events**
- `phase_name` field only populates when PDE workflow commands emit events
- Hook-only sessions show "No active phase" (graceful degradation, not a crash)
- Affected: MON-01, DSH-03, DSH-04 (operational dependency)

**INT-03 (Info): Schema version divergence**
- `relay-protocol.cjs` uses zod v3 (`z.record(z.unknown())`)
- `dashboard/lib/wire-schema.ts` uses zod v4 (`z.record(z.string(), z.unknown())`)
- Both accept identical runtime data — no break, but schemas cannot be unified without version alignment
