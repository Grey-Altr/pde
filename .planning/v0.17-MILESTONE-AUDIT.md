### Critical Finding

**INT-01: /api/approval-response missing from Clerk public matcher (proxy.ts)**
- `proxy.ts` declares only `/sign-in(.*)` and `/api/ingest` as public routes
- Relay daemon calls GET `/api/approval-response` with Bearer token (no Clerk session)
- Clerk middleware intercepts with 401 before route handler's `validateRelayToken` runs
- **Result:** `getApprovalResponse` always returns null → PDE remains blocked indefinitely
- **Affected:** APR-04
- **Fix:** Add `'/api/approval-response'` to `isPublicRoute` matcher in `dashboard/proxy.ts`

### Secondary Findings

**INT-02 (Medium): /api/cron/gc possibly blocked by Clerk middleware**
- Same pattern as INT-01 — not in public matcher, Vercel cron has no Clerk session
- Affected: HRD-05
- Fix: Add `'/api/cron/gc'` to public matcher

**INT-03 (Low): Push sendPushToOwner is fire-and-forget**
- `sendPushToOwner(...).catch(() => {})` — delivery failures invisible
- Affected: PWA-02 (cosmetic — delivery works, just no logging)
