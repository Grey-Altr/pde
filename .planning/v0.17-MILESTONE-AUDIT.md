### Critical Integration Gap

**APR-04: Approval response delivery to PDE**

- relay.cjs polls GET /api/approval-response every 3s and correctly retrieves responses
- Phase 140 fixed the Clerk public route matcher so the GET reaches the handler
- relay.cjs writes the response as NDJSON to process.stdout
- **But** hooks/start-relay.cjs:80 spawns the relay daemon with stdio: 'ignore' — stdout goes to /dev/null
- PDE never receives the approval response, so approval gates cannot be unblocked via the dashboard

**Fix:** Change the relay stdout mechanism — either pipe to a named file that PDE reads, or have the relay write approval responses to a PDE-side file directly.
