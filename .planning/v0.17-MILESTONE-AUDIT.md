## Critical Integration Issue

### Session ID Namespace Mismatch

**Severity:** Critical (blocks RLY-01 in production, transitively blocks DSH-01 through DSH-06)
**Assigned to:** Phase 134.1 (gap closure)

**From:** `hooks/start-relay.cjs:43` — `hookData.session_id` (Claude Code conversation ID)
**To:** `bin/lib/event-bus.cjs:50` — writes NDJSON using UUID from `generateSessionId()` stored in `.planning/config.json`

The relay daemon watches `/tmp/pde-session-{claude-conv-id}.ndjson` but PDE events are written to `/tmp/pde-session-{pde-random-uuid}.ndjson`. In production, the relay tails a file that never gets written to.

**Why tests pass:** Integration tests call `startRelay()` directly with a consistent UUID, bypassing the hook spawn path.

**Fix path:** `start-relay.cjs` should read `config.monitoring.session_id` from `.planning/config.json` (written synchronously by `emit-event.cjs` before `start-relay.cjs` runs via hook ordering: async:false before async:true).
