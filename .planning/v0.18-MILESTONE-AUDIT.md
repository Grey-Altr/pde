### Integration Issues

**INT-01 (High — Security):** `/api/sessions` missing authentication

`dashboard/app/api/sessions/route.ts` has no `auth()` guard. Any HTTP client can enumerate active sessions. The comparable `/api/poll/route.ts` correctly uses `auth()` from `@clerk/nextjs/server`. Fix: add Clerk auth guard matching the existing pattern.

Affected: DSH-01, DSH-02, DSH-05, DSH-12

**INT-02 (Medium — Incomplete Feature):** FailureCard action buttons are no-ops

`page.tsx` renders `<FailureCard session={s} />` without handler props. Buttons render and are clickable but silently no-op. No server action or API route exists for session retry/abandon/kill. Documented as known stub in 147-05 SUMMARY.

Affected: DSH-06 (UI complete, backend unwired)

**INT-03 (Low — Test Infrastructure):** coordinator-smoke Test 7 timeout

`coordinator-smoke.test.cjs` Test 7 hangs because `makeCoordWithDeps` doesn't inject stubs for `analyzeDag`/`routeSession` from Phases 145/146. Real SDK call hangs without credentials. Not a production issue. Tracked in `deferred-items.md`.

Affected: DSP-05, SDK-02 (test coverage gap only)
