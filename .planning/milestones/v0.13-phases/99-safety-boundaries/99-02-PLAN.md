For each of the 7 workflow files, add paired `<!-- LOCKED -->` / `<!-- /LOCKED -->` and `<!-- OPTIMIZABLE -->` / `<!-- /OPTIMIZABLE -->` HTML comment markers around sections. The markers wrap entire named sections (## headings), not individual lines.

**Marker syntax:**
- Opening: `<!-- LOCKED: {brief description} -->` (description is optional but recommended)
- Closing: `<!-- /LOCKED -->`
- Opening: `<!-- OPTIMIZABLE: {brief description} -->`
- Closing: `<!-- /OPTIMIZABLE -->`

**What to mark LOCKED in every file:**
1. Everything before the first `## Step` heading: `<purpose>`, `<required_reading>`, `<flags>`, `<process>` opening tag
2. Step 1 (init step) — contains `pde-tools.cjs` calls, JSON parsing, prerequisite validation
3. Any step that writes artifact codes (e.g., `BRF`, `SYS`, `FLW`, `CRT`, etc.) or `designCoverage` fields (e.g., `hasBrief`, `hasDesignSystem`, `hasFlows`, etc.)
4. Any step that writes file paths matching artifact naming patterns
5. Error message strings that are asserted by Nyquist tests (search tests/ for the workflow filename to find asserted strings)
6. MCP probe blocks (`bridge.call()` patterns)
7. The `</process>` closing tag

**What to mark OPTIMIZABLE:**
1. Steps containing prose guidance about HOW to generate content (e.g., "Evaluate from four perspectives...", "Generate design tokens for...")
2. Example output sections within steps
3. Heuristic ordering guidance (e.g., which perspectives to evaluate first)
4. Prompt phrasing for agent instructions

**Per-file specifics from research:**

- **brief.md**: LOCKED = init step, artifact code `BRF`, `hasBrief` write, file path pattern, MCP probe. OPTIMIZABLE = brief generation prompts, question phrasing, output structure guidance.
- **system.md**: LOCKED = init step, artifact code `SYS`, `hasDesignSystem` write, token JSON schema field names. OPTIMIZABLE = token generation guidance, category ordering, design prose.
- **flows.md**: LOCKED = init step, artifact code `FLW`, `hasFlows` write, DESIGN-STATE fields. OPTIMIZABLE = flow diagram guidance, persona labeling, journey narration.
- **ideate.md**: LOCKED = init step, artifact code, `hasIdeation` write. OPTIMIZABLE = ideation prompts, concept framing, output format.
- **wireframe.md**: LOCKED = init step, `hasWireframes` write, Stitch integration contract, token path assertion. OPTIMIZABLE = wireframe guidance, layout prompts, annotation style.
- **critique.md**: LOCKED = init step, artifact code `CRT`, `hasCritique` write, Awwwards dimension weights and names (`Design 40`, `Usability 30`, `Creativity 20`, `Content 10`), `quality-standards.md` required_reading, `score impact` phrasing. OPTIMIZABLE = critique perspective ordering, rubric description text (NOT the weight numbers or dimension names).
- **hig.md**: LOCKED = init step, `hasHIG` write, required_reading block. OPTIMIZABLE = HIG evaluation prose, platform guidance.

**CRITICAL for critique.md:** The Awwwards dimension weights (`Design 40%`, `Usability 30%`, `Creativity 20%`, `Content 10%`) and the `score impact` language are asserted by Nyquist tests. These MUST be inside LOCKED sections even though they appear to be prose. Search tests/ for "critique" and "Design 40" to confirm which strings are asserted.

**Verification before saving each file:** After adding markers, ensure:
1. At least one `<!-- LOCKED -->` and one `<!-- /LOCKED -->` pair exists
2. At least one `<!-- OPTIMIZABLE -->` and one `<!-- /OPTIMIZABLE -->` pair exists
3. Markers are properly paired (every open has a close)
4. No marker is nested inside another marker of the same type

const fs = require('fs');
const files = ['brief','system','flows','ideate','wireframe','critique','hig'];
let allPass = true;
for (const f of files) {
  const c = fs.readFileSync('workflows/' + f + '.md', 'utf8');
  const hasLO = c.includes('<!-- LOCKED');
  const hasLC = c.includes('<!-- /LOCKED -->');
  const hasOO = c.includes('<!-- OPTIMIZABLE');
  const hasOC = c.includes('<!-- /OPTIMIZABLE -->');
  const lockCount = (c.match(/<!-- LOCKED/g)||[]).length;
  const unlockCount = (c.match(/<!-- \/LOCKED -->/g)||[]).length;
  const optCount = (c.match(/<!-- OPTIMIZABLE/g)||[]).length;
  const unoptCount = (c.match(/<!-- \/OPTIMIZABLE -->/g)||[]).length;
  const paired = lockCount === unlockCount && optCount === unoptCount;
  const pass = hasLO && hasLC && hasOO && hasOC && paired;
  if (!pass) { console.log('FAIL: ' + f + '.md — locked:' + lockCount + '/' + unlockCount + ' opt:' + optCount + '/' + unoptCount); allPass = false; }
  else { console.log('OK: ' + f + '.md — ' + lockCount + ' locked, ' + optCount + ' optimizable sections'); }
}
process.exit(allPass ? 0 : 1);
"</automated>
