    IMPORTANT: Since experiment.cjs calls output() which does process.exit(0), the tests must NOT call the cmd* functions directly in-process. Instead, either: (a) mock process.exit and capture stdout, or (b) extract internal helper functions that return values and test those, with cmd* wrappers being thin output() callers.     Then implement bin/lib/experiment.cjs (under 300 lines) with these functions:

    1. cmdExperimentInit(cwd, slug, raw) — validates slug against /^[a-z0-9-]+$/, reads HEAD SHA as baseline, creates experiment/slug branch via execGit, creates .planning/experiments/slug/ dir, writes initial EXPERIMENT-BEST.json with slug, branch, baseline, bestMetric: null, bestCommit: null, iteration: 0. Outputs initialized: true, branch, baseline.

    2. cmdExperimentCommit(cwd, slug, metric, description, raw) — reads current EXPERIMENT-BEST.json, stages all changes via execGit add -A, commits with message experiment(slug): description, reads new commit SHA, increments iteration. If metric is better than bestMetric (or bestMetric is null), updates bestMetric and bestCommit. Metric comparison uses direction field from EXPERIMENT-BEST.json (default max). Writes updated state. Outputs committed: true, commit, iteration, metric, isBest.

    3. cmdExperimentReset(cwd, slug, raw) — reads HEAD commit subject via execGit log --format=%s -1 HEAD. Checks subject starts with experiment(slug):. Also checks current branch is experiment/slug via execGit rev-parse --abbrev-ref HEAD. If both pass: execGit reset --hard HEAD~1. If either fails: outputs reset: false, reason: prefix_mismatch or wrong_branch, without any git mutation.

    4. cmdExperimentPromote(cwd, slug, raw) — reads EXPERIMENT-BEST.json. If no bestCommit, outputs error. Otherwise: checkout main, cherry-pick bestCommit. Outputs promoted: true, commit, slug.

    5. cmdExperimentStatus(cwd, slug, raw) — reads EXPERIMENT-BEST.json. If missing, outputs found: false, slug. Otherwise outputs found: true plus all state fields.

    6. cmdExperimentCleanup(cwd, slug, raw) — switches to main, deletes experiment/slug branch via git branch -D. Outputs cleaned: true, slug.

    7. checkBoundaries(cwd, mutableFiles) — reads references/experiment-boundaries.md YAML frontmatter via simple line-by-line parser (no YAML library). Extracts protected_files and protected_directories arrays. For each mutableFile, checks against both lists. Returns valid: true/false with violations array.

    All git operations go through execGit from core.cjs. Module begins with 'use strict' and ends with module.exports exporting all 7 public functions plus the underscore helpers for testing.

    - Reset MUST verify both commit prefix AND current branch before executing (Pitfall 1 and 2)
