    **Function signature:**
    ```javascript
    function spawnSession(opts)
    // opts: { worktreePath, sessionId, phase, plan, pluginDir, extraArgs?, onLine, onExit }
    // returns: { pid: number, kill: function }
    ```

    **Critical implementation rules (all verified in research):**
    1. Build env with `const env = { ...process.env }; delete env.CLAUDECODE;` — CLAUDECODE=1 blocks nested launch
    2. Set `env.PDE_SESSION_ID = sessionId`, `env.PDE_PHASE = String(phase)`, `env.PDE_PLAN = String(plan)`, `env.PDE_SESSION_START = String(Date.now())`
    3. Args array: `['--print', '--bare', '--output-format', 'stream-json', '--verbose', '--dangerously-skip-permissions', '--plugin-dir', pluginDir, '--append-system-prompt', '<autonomous mode instruction>', ...extraArgs, prompt]`
    4. The prompt (last positional arg): `Execute phase ${phase}, plan ${plan}. Run /gsd:execute-plan ${phase} ${plan}.`
    5. `spawn('claude', args, { cwd: worktreePath, env, stdio: ['ignore', 'pipe', 'pipe'] })` — stdin MUST be 'ignore'
    6. Use `readline.createInterface({ input: child.stdout, crlfDelay: Infinity })` for line-by-line NDJSON parsing
    7. Each line: try JSON.parse, call `onLine(sessionId, parsed)`. Non-JSON lines silently skipped.
    8. Stderr: `child.stderr.on('data', ...)` → `onLine(sessionId, { type: 'system', subtype: 'stderr', message: msg })`
    9. Close: `child.on('close', exitCode => { rl.close(); onExit(sessionId, exitCode ?? 1); })`
    10. Return `{ pid: child.pid, kill: (signal = 'SIGTERM') => child.kill(signal) }`
