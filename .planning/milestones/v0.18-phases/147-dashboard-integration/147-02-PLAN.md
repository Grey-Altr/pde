    1. Create `dashboard/components/session-health-matrix.tsx`:
       - "use client" component
       - Props: `{ sessions: SessionListItem[] }`
       - Renders a table with columns: Status (StatusBadge), Phase, Source, Runtime
       - Each row has a colored left border using `sessionColor(index)` from session-colors.ts
       - Source column displays human-readable label: 'local' -> 'Local', 'remote-ssh' -> 'SSH', 'remote-managed' -> 'Managed'
       - Runtime column shows elapsed time since startedAt using `formatElapsed` helper (same pattern as session-card.tsx)
       - Each row is clickable via Link to `/sessions/${session.id}`
       - Uses Card wrapper for consistent styling
       - Empty state: "No active sessions" message

    2. Create `dashboard/components/aggregate-status-bar.tsx`:
       - "use client" component
       - Props: `{ sessions: SessionListItem[] }`
       - Derives from sessions array:
         - `activeCount`: sessions.filter(s => s.status === 'active').length
         - `queuedCount`: sessions.filter(s => s.status === 'queued').length
         - `failedCount`: sessions.filter(s => s.status === 'failed' || s.status === 'error').length
         - `totalCost`: placeholder '—' (cost data comes from events, not session metadata; will be wired when event data available)
       - Renders horizontal row of stat pills: "3 Active", "1 Queued", "0 Failed", "Cost: —"
       - Uses Badge component for each pill
       - Active = green tint, Queued = amber tint, Failed = red tint
       - Compact layout for bottom status bar usage

    3. Create `dashboard/__tests__/aggregate-status.test.ts`:
       - Test: counts active, queued, failed correctly from mock SessionListItem[]
       - Test: handles empty sessions array
       - Test: handles mixed statuses
