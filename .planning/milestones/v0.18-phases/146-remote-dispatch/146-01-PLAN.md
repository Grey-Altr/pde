Create `packages/dispatcher/lib/remote-router.cjs`:
- Single exported async function `routeSession({ isAutonomous, remoteConfig, _detectManaged })`
- `_detectManaged` is injectable for testing (default: `require('./remote-managed.cjs').detectManagedBackend`)
- Decision tree (in this exact order):
  1. `!isAutonomous` -> return `'local'` (RMT-05: interactive sessions always local)
  2. `!remoteConfig || !remoteConfig.host` -> return `'local'` (no config = local)
  3. `remoteConfig.preferred_backend === 'managed'` -> call `_detectManaged()`, if `available` return `'managed'`, otherwise continue
  4. `remoteConfig.host` exists -> return `'ssh'`
  5. Default fallback -> return `'local'`
- Returns: `Promise<'local' | 'ssh' | 'managed'>`
- Module pattern: `'use strict';` at top, `module.exports = { routeSession };` at bottom
