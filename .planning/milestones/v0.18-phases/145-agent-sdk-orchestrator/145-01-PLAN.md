       - `'use strict';` header
       - Module-scoped `let _sdkModule = null;` for lazy caching
       - `async function _loadSdk()`: uses `await import('@anthropic-ai/claude-agent-sdk')`, caches in `_sdkModule`, returns it. CRITICAL: use dynamic `import()` NOT `require()` — the SDK is ESM-only, Node 20 does not support `require()` of ESM.
       - `async function sdkQuery(prompt, options)`:
         - Calls `_loadSdk()` to get the SDK module
         - Calls `sdk.query({ prompt, options: options || {} })` — returns an async iterable

         - If `message.type === 'result' && message.subtype === 'success'`: capture `message.result`
         - If `message.type === 'result'` and subtype is NOT `'success'`: throw `new Error('SDK query failed: ' + ((message.errors || []).join('; ') || message.subtype))`
         - Returns the captured result string, or `''` if no result message appeared
       - Export: `module.exports = { sdkQuery };`
       - Do NOT export `_loadSdk` (internal)

    - `const q = _sdkQuery || sdkQuery;` for DI
    - Reads `.planning/ROADMAP.md` path (constructs via `path.join(projectRoot, '.planning', 'ROADMAP.md')`)

    - Wraps `q()` in try/catch — on ANY error OR JSON.parse failure, return `{ parallelizable: [], unsafe: [] }`
    - Returns parsed JSON object

    **2. `checkFileOverlap(projectRoot, phases)` (SDK-03)**
    - DOES NOT use SDK — pure static analysis (per research Pattern 3)
    - Scans `.planning/phases/` directories for PLAN.md files matching each phase number
    - For each PLAN.md, extracts `files_modified` from YAML frontmatter using regex:
      - Match `^---\n([\s\S]*?)\n---` for frontmatter block
      - Match `files_modified:\s*\n((?:\s+-\s+.+\n?)*)` for the list
      - Extract each `^\s+-\s+(.+)$` line
    - For each pair of phases, find intersection of files_modified sets
    - Returns `{ overlapping: Array<{phases: number[], files: string[]}> }`
    - Helper `_findPlanDir(projectRoot, phase)`: scans `.planning/phases/` for directory matching phase number prefix (e.g., `145-*`)
    - Helper `_extractFilesModified(planDir, phase)`: extracts files from all PLAN.md in dir
    - Both helpers are module-internal (not exported)

    - Extracts last 50 non-empty lines
    - If file missing or empty, returns `'No session log available.'`
    - Calls `q(prompt, { allowedTools: [], permissionMode: 'dontAsk', maxTurns: 1 })`
    - Prompt: includes NDJSON tail in code block, asks for 2-3 sentence summary of what failed
    - Wraps in try/catch — on error returns `'Failed to generate summary.'`

    **4. `triageConflicts(conflictFiles, projectRoot, _sdkQuery)` (SDK-05)**
    - For each file in conflictFiles array, reads up to 3000 chars from `path.join(projectRoot, file)`
    - If read fails, includes `(could not read)` placeholder
    - Calls `q(prompt, { allowedTools: [], permissionMode: 'dontAsk', maxTurns: 1 })`
    - Prompt: lists conflict files, includes content with conflict markers, asks for per-file resolution strategy
    - Wraps in try/catch — on error returns `'Failed to generate conflict triage.'`
