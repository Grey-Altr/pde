    - Test 3: _pde_session_source is 'L' when registry.get(sessionId).backend === 'local', 'R' when 'ssh', 'R' when 'managed'
    - Test 4: _pde_session_source defaults to 'L' when registry.get(sessionId) returns undefined

    - Test 6: stop() removes the event listener (aggregator emits after stop, nothing written)
  </behavior>
  <action>
    Create `packages/dispatcher/lib/tmux-fanout.cjs` as a CJS module exporting `{ TmuxFanout, FANOUT_PATH, FILTER_PATH }`.

    Constants:
    - `FANOUT_PATH = path.join(os.tmpdir(), 'pde-multi-session.ndjson')`
    - `FILTER_PATH = path.join(os.tmpdir(), 'pde-tmux-filter.txt')`

    Helper function `sourceLabel(backend)`:
    - `'local'` returns `'L'`
    - anything else (`'ssh'`, `'managed'`, undefined) returns `'R'`

    Class `TmuxFanout`:
    - Constructor: `(aggregator, registry)` — stores both, creates `this._sessionIndex = new Map()` and `this._nextIndex = 0`, `this._handler = null`
    - `start()`: Truncates FANOUT_PATH with `fs.writeFileSync(FANOUT_PATH, '', 'utf8')` wrapped in try/catch. Sets `this._handler` to a function that:
      1. Assigns color index: if sessionId not in `_sessionIndex`, sets `_sessionIndex.set(sessionId, (this._nextIndex++) % 6)`
      2. Reads `this._registry.get(sessionId)` for backend field
      3. Builds enriched object: `{ ...event, _pde_session_id: sessionId, _pde_session_source: sourceLabel(entry?.backend), _pde_color_index: this._sessionIndex.get(sessionId) }`
      4. Appends `JSON.stringify(enriched) + '\n'` to FANOUT_PATH via `fs.appendFileSync` wrapped in try/catch (never crash coordinator)
      5. Calls `this._aggregator.on('event', this._handler)`
    - `stop()`: If `this._handler`, calls `this._aggregator.off('event', this._handler)` and sets `this._handler = null`

    Create `tests/dispatcher/tmux-fanout.test.cjs` using vitest with the behavior cases above. Use a real EventEmitter as mock aggregator. Use a Map-based mock registry with `.get(id)` returning `{ backend: 'local' }` or `{ backend: 'ssh' }`. Read FANOUT_PATH after each emit to verify written content. Use a unique temp file path (e.g., `os.tmpdir() + '/pde-test-fanout-' + process.pid + '.ndjson'`) to avoid collisions — override FANOUT_PATH via a test helper or by directly setting the module constant before test.

    Since FANOUT_PATH is a module-level const, use `vi.mock('node:os', ...)` to redirect `os.tmpdir()` to a test-specific temp dir, OR create TmuxFanout with a custom `_fanoutPath` constructor option for testability. Choose the simpler approach: add an optional third constructor arg `opts = {}` with `opts.fanoutPath` that overrides `FANOUT_PATH` for testing. The exported `FANOUT_PATH` constant remains for production use.
