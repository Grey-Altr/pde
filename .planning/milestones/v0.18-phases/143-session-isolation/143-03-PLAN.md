<objective>
Migrate executor write protocol to session-scoped artifacts when PDE_SESSION_ID is present.

Purpose: This is the single-writer correctness protocol. Without it, parallel executors would race on STATE.md and REQUIREMENTS.md, causing corrupted data. By writing to session-scoped artifacts (COMPLETE.json, COMPLETED-REQS.md), each session is isolated and the dispatcher recalculates shared state post-merge.

Output: New session-artifacts.cjs module and gating logic in pde-tools.cjs/state.cjs/milestone.cjs that routes writes to session-scoped paths when PDE_SESSION_ID is set, leaving all existing behavior unchanged when it is not.
</objective>
