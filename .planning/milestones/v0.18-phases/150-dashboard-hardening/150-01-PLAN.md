**HDN-01: Auth guard on /api/sessions/route.ts**

Add the Clerk auth guard to the existing GET handler. The file currently has no auth check. Add `import { auth } from '@clerk/nextjs/server'` and the standard guard at the top of the GET function body:

```typescript
export const dynamic = 'force-dynamic';

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import { getSessions } from '@/lib/queries';

export async function GET(): Promise<NextResponse> {
  const { isAuthenticated } = await auth();
  if (!isAuthenticated) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
  }

  const sessions = await getSessions();
  return NextResponse.json(sessions);
}
```

Do NOT add `/api/sessions` to PUBLIC_ROUTES in `proxy.ts`. It must stay protected by Clerk middleware as defence-in-depth.

Add a shared helper function (not exported):

```typescript
type ActionResult = { ok: boolean; error?: string };

function readRegistry(): { sessions: Record<string, { pid: number; phase: number; plan: number; worktreePath: string; branch: string; status: string; startedAt: string }> } | null {
  const projectRoot = process.env.PDE_PROJECT_ROOT;
  if (!projectRoot) return null;
  const pidFile = path.join(projectRoot, '.planning', 'dispatcher.pids');
  try {
    return JSON.parse(readFileSync(pidFile, 'utf-8'));
  } catch {
    return null;
  }
}

function writeRegistry(data: ReturnType<typeof readRegistry>): boolean {
  const projectRoot = process.env.PDE_PROJECT_ROOT;
  if (!projectRoot || !data) return false;
  const pidFile = path.join(projectRoot, '.planning', 'dispatcher.pids');
  try {
    writeFileSync(pidFile, JSON.stringify(data, null, 2));
    return true;
  } catch {
    return false;
  }
}
```

Add three exported server actions:

1. `retrySession(sessionId: string): Promise<ActionResult>` — Per user decision, implement as error-returning stub. Must still call `auth()` and validate sessionId exists in registry:
   - Call `auth()`, return `{ ok: false, error: 'Unauthorized' }` if not authenticated
   - Read registry, validate session exists
   - Return `{ ok: false, error: 'retry-requires-local-dispatcher' }`

2. `abandonSession(sessionId: string): Promise<ActionResult>` — Per user decision, set status to `'abandoned'` AND schedule worktree cleanup:
   - Call `auth()`, return `{ ok: false, error: 'Unauthorized' }` if not authenticated
   - Read registry via `readRegistry()`, return `{ ok: false, error: 'PDE_PROJECT_ROOT not set — session actions only work locally' }` if null
   - Find session entry, return `{ ok: false, error: 'Session not found' }` if missing
   - Set `entry.status = 'abandoned'`, write registry back
   - Schedule worktree cleanup: write a file at `path.join(projectRoot, '.planning', 'cleanup-requests', sessionId)` containing JSON `{ sessionId, worktreePath: entry.worktreePath, branch: entry.branch, requestedAt: new Date().toISOString() }`. Create the `cleanup-requests` directory with `mkdirSync(..., { recursive: true })` if it does not exist
   - Return `{ ok: true }`

3. `killSession(sessionId: string): Promise<ActionResult>` — Send SIGTERM and update registry:
   - Call `auth()`, return `{ ok: false, error: 'Unauthorized' }` if not authenticated
   - Read registry via `readRegistry()`, return error if null
   - Find session entry, return error if missing
   - If `entry.pid > 0`, wrap `process.kill(entry.pid, 'SIGTERM')` in try/catch (ignore ESRCH — process already dead)
   - Set `entry.status = 'stopped'`, write registry back
   - Return `{ ok: true }`
