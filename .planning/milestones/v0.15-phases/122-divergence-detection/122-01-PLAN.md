    ## DIV-01: T1 Structural Detection
    - extractAnnotations('<!-- @component: Button -->') returns [{ name: 'Button', props: null, tokens: [] }]
    - extractAnnotations with @component + @props + @tokens returns full ComponentSpec
    - extractAnnotations on content with no annotations returns []
    - findComponentFile returns file path when Button.tsx exists (case-insensitive match)
    - findComponentFile returns null when component file does not exist
    - findComponentFile skips node_modules and dotdirs
    - findComponentFile matches .tsx, .ts, .jsx, .js, .vue, .svelte extensions

    ## DIV-02: T2 Content Detection
    - extractPropsFromFile extracts prop names from 'interface ButtonProps { label: string; onClick: () => void; }' -> ['label', 'onClick']
    - extractPropsFromFile returns null when interface not found
    - extractPropsFromFile handles optional props (name?: type) correctly
    - extractPropsFromFile handles generic props (e.g., MouseEvent<HTMLButtonElement>) without breaking on nested braces
    - T2 comparison: handoff props ['label', 'onClick'] vs file props ['label', 'onClick'] -> ALIGNED
    - T2 comparison: handoff props ['label', 'onClick', 'variant'] vs file props ['label', 'onClick'] -> DRIFTED (missing: variant)

    ## DIV-03: T3 Behavioral Detection
    - checkTokenUsage('color: var(--color-primary-500)', ['--color-primary-500']) returns [] (all used)
    - checkTokenUsage('color: red', ['--color-primary-500']) returns ['--color-primary-500'] (missing)
    - checkTokenUsage with empty tokens list returns []

    ## DIV-04: DIVERGENCE.md Output
    - buildDivergenceReport produces markdown with table rows for each component
    - buildDivergenceReport includes ALIGNED/DRIFTED/MISSING/EXTRA statuses
    - buildDivergenceReport includes summary counts
    - buildDivergenceReport includes suppression count when ignore list is active

    ## DIV-06: Ignore Mechanism
    - loadIgnoreList returns Set of component names from .pde-divergence-ignore
    - loadIgnoreList skips comment lines (starting with #) and empty lines
    - loadIgnoreList returns empty Set when file does not exist
    - runDivergenceCheck excludes ignored components from results

    ## Integration: runDivergenceCheck
    - Returns { components: [...], noSpecs: false } with per-component status
    - Returns { components: [], noSpecs: true } when no handoff specs exist
    - Each component has: name, status (ALIGNED|DRIFTED|MISSING|EXTRA), t1/t2/t3 details
