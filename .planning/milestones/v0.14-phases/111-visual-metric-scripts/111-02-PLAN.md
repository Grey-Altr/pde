    **bin/responsive-metric.cjs (VIS-04):**
    TIMEOUT_MS = 45000 (longer — 3 resize+evaluate cycles). This is the most complex script. Multi-step orchestration:

    1. Construct file URL: `'file://' + encodeURI(path.resolve(filePath))`
    2. Navigate: `bridge.call('playwright:navigate', { url: fileUrl })`
    3. For each breakpoint `[{w:1280, h:800}, {w:768, h:1024}, {w:375, h:812}]`:
       a. Resize: `bridge.call('playwright:resize', { width: w, height: h })`
       b. Evaluate layout signature via `bridge.call('playwright:evaluate', { function: layoutSignatureJS })`
       where layoutSignatureJS is the inline function from research "Responsive Compliance Layout Signature":
       ```
       (() => {
         try {
           const body = document.body;
           const main = document.querySelector('main') || body;
           const nav = document.querySelector('nav');
           const overflow = document.documentElement.scrollWidth > document.documentElement.clientWidth;
           const interactiveEls = [...document.querySelectorAll('a[href],button,[role="button"],input,select,textarea')];
           const touchTargets = interactiveEls.filter(el => {
             const r = el.getBoundingClientRect();
             return r.width >= 44 && r.height >= 44;
           });
           return {
             bodyWidth: body.clientWidth,
             mainWidth: main.clientWidth,
             navDisplay: nav ? getComputedStyle(nav).display : null,
             navFlexDir: nav ? getComputedStyle(nav).flexDirection : null,
             overflow,
             fontSize: parseFloat(getComputedStyle(body).fontSize),
             touchTargetRatio: interactiveEls.length > 0 ? touchTargets.length / interactiveEls.length : 1,
             gridCols: getComputedStyle(main).gridTemplateColumns || null,
           };
         } catch (e) { return { overflow: false, touchTargetRatio: 1, fontSize: 16 }; }
       })()
       ```
    4. Score computation from 3 signatures (desktop, tablet, mobile):
       - No overflow at any breakpoint: +25 (per breakpoint without overflow)
       - Touch targets >= 44px ratio at mobile: `Math.round(mobileSig.touchTargetRatio * 25)` (max 25)
       - Layout adaptation detected (desktop gridCols differs from mobile gridCols, or nav flexDirection changes): +15
       - Font readable at mobile (fontSize >= 14): +10
       - Total score = `Math.round(Math.max(0, Math.min(100, score)))`
    5. Close: `bridge.call('playwright:close', {})`

    **bin/mermaid-metric.cjs (VIS-05):**
    TIMEOUT_MS = 30000. This script generates a temp HTML file, renders Mermaid via CDN, and scores the result.

    1. Read file from `process.argv[2]` via `fs.readFileSync(filePath, 'utf-8')`
    2. Extract Mermaid definition: look for ````mermaid` fenced block, extract content between the fences. If no Mermaid block found, try treating entire file content as Mermaid syntax.
    3. Generate temp HTML file at `/tmp/mermaid-${Date.now()}.html` using the template from research "Mermaid HTML Template":
       ```html
       <!DOCTYPE html>
       <html>
       <head>
         <meta charset="UTF-8">
         <style>body { margin: 0; padding: 16px; background: #fff; } #output { width: 100%; }</style>
       </head>
       <body>
         <div id="output"></div>
         <script type="module">
           import mermaid from 'https://cdn.jsdelivr.net/npm/mermaid@11/dist/mermaid.esm.min.mjs';
           const definition = `MERMAID_DEFINITION_HERE`;
           mermaid.initialize({ startOnLoad: false, securityLevel: 'loose', theme: 'default',
             flowchart: { useMaxWidth: false, htmlLabels: true, curve: 'basis' } });
           try {
             const { svg } = await mermaid.render('mermaid-diagram', definition);
             document.getElementById('output').insertAdjacentHTML('beforeend', svg);
             window.__MERMAID_RENDERED__ = true;
           } catch (err) {
             window.__MERMAID_RENDERED__ = false;
             window.__MERMAID_ERROR__ = err.message;
           }
         </script>
       </body>
       </html>
       ```
       Replace `MERMAID_DEFINITION_HERE` with the extracted definition (escape backticks in definition string).
    4. Navigate: `bridge.call('playwright:navigate', { url: 'file://' + encodeURI(tmpPath) })`
    5. Poll `__MERMAID_RENDERED__` up to 5 times, 500ms apart via `bridge.call('playwright:evaluate', { function: '(() => window.__MERMAID_RENDERED__)()' })`
    6. If rendered, extract metrics via `bridge.call('playwright:evaluate', { function: fullMetricExtractionJS })` where fullMetricExtractionJS is the inline function from research "Mermaid Full Metric Extraction":
       - nodeCount: `.node` selector
       - edgeCount: `.edgePaths path, .flowchart-link` selectors (correct Mermaid v11 classes per research finding)
       - crossings: bounding box overlap heuristic
       - svgWidth, svgHeight
       - tooSmallFonts: text elements with fontSize < 12px
    7. Score computation from extracted metrics:
       - Nodes present: `Math.min(20, nodeCount * 5)` (max 20)
       - Edges present: `Math.min(20, edgeCount * 5)` (max 20)
       - No edge crossings: `Math.max(0, 20 - crossings * 5)` (max 20)
       - Readable text (no tiny fonts): `tooSmallFonts === 0 ? 20 : Math.max(0, 20 - tooSmallFonts * 5)` (max 20)
       - Reasonable diagram size (not clipped): `(svgWidth <= vw && svgHeight <= vh * 3) ? 20 : 10` (max 20)
       - Total score = `Math.round(Math.max(0, Math.min(100, score)))`
    8. Close browser: `bridge.call('playwright:close', {})`
    9. Cleanup temp file: `try { fs.unlinkSync(tmpPath); } catch(_) {}`
