    Create 3 metric scripts following the _evalMetric contract. Each script must:
    - Start with `#!/usr/bin/env node` and `'use strict';`
    - Use `const path = require('path'); const bridge = require(path.join(__dirname, 'lib', 'mcp-bridge.cjs'));`
    - Check `process.argv[2]` — if missing, write '0\n' to stdout and exit 0 (VIS-07)
    - Probe Playwright via `try { bridge.call('playwright:probe', {}); } catch(_) { /* unavailable */ }` — if call throws (key not in TOOL_MAP), write '0\n' and exit 0 (VIS-07)
    - Set internal timeout via `setTimeout(() => { process.stdout.write('0\n'); process.exit(0); }, TIMEOUT_MS)` (VIS-06)
    - All diagnostic output goes to `process.stderr.write()`, never `console.log()`
    - Only the final score number goes to `process.stdout.write(String(score) + '\n')`
    - Always `process.exit(0)` — never exit non-zero
    - Wrap async work in `async function run() { try { ... } catch(_) { process.stdout.write('0\n'); process.exit(0); } }; run();`
    - Call `bridge.call('playwright:close', {})` in a finally block

    **bin/dom-metric.cjs (VIS-01):**
    TIMEOUT_MS = 30000. After navigation via `bridge.call('playwright:navigate', { url: fileUrl })`, use `bridge.call('playwright:evaluate', { ... })` with inline JS from research "DOM Score Computation" section:
    - Count unique tag names (diversity): `Math.min(15, (allTags.size / 15) * 15)`
    - Count landmarks (header, nav, main, footer, aside, section, article + ARIA roles): `Math.min(20, (landmarkCount / 5) * 20)`
    - Check h1 presence: +10
    - Penalize heading skips: -3 per skip
    - Count interactive elements (a[href], button, input, select, textarea): `Math.min(15, (interactiveCount / 8) * 15)`
    - Count total elements (complexity): `Math.min(15, (totalElements / 50) * 15)`
    - Score = `Math.round(Math.max(0, Math.min(100, score)))`
    - The `bridge.call('playwright:evaluate', ...)` returns `{ toolName: 'mcp__playwright__browser_evaluate', args: { function: '...' } }` — the script stores this as the resolved tool call for the workflow layer
    - Construct file URL with `'file://' + encodeURI(path.resolve(filePath))`

    **bin/a11y-metric.cjs (VIS-02):**
    TIMEOUT_MS = 30000. Uses `bridge.call('playwright:snapshot', {})` instead of browser_evaluate (per research Pattern 5). After navigation:
    - Get AOM tree text via `bridge.call('playwright:snapshot', {})`
    - Parse AOM text with regex for violations:
      - Missing main landmark: `!/\b(main|role="main")\b/i.test(aomText) && !/- main\b/.test(aomText)` → +1 violation
      - Missing navigation: similar pattern → +1 violation
      - Missing banner: similar pattern → +1 violation
      - Unlabeled controls: `(aomText.match(/- (button|link|textbox|combobox|checkbox|radio)\s+""\s/gi) || []).length` → add each
      - Heading hierarchy: parse `- heading "..." level N` lines, check for skips (level jumps > 1)
    - Score = `Math.max(0, 100 - violations * 10)`

    **bin/contrast-metric.cjs (VIS-03):**
    TIMEOUT_MS = 30000. Uses `bridge.call('playwright:evaluate', { ... })` with the complete WCAG contrast evaluation script from research. The inline JS contains:
    - `sRGBtoLinear(c)` function: `s <= 0.04045 ? s / 12.92 : Math.pow((s + 0.055) / 1.055, 2.4)`
    - `luminance(r, g, b)` function: `0.2126 * sRGBtoLinear(r) + 0.7152 * sRGBtoLinear(g) + 0.0722 * sRGBtoLinear(b)`
    - `contrastRatio(fg, bg)` function: `(Math.max(L1, L2) + 0.05) / (Math.min(L1, L2) + 0.05)`
    - `parseRGBA(str)` function: parses `rgb(r,g,b)` and `rgba(r,g,b,a)` strings
    - `getEffectiveBg(el)` function: walks `parentElement` chain until finding non-transparent background, defaults to `[255, 255, 255]` at root
    - Iterates over `document.querySelectorAll('h1,h2,h3,h4,h5,h6,p,span,a,li,td,th,label,button')`
    - Skips `display:none` and `visibility:hidden` elements
    - Skips elements with no text content (childNodes nodeType === 3)
    - AA threshold: large text (>= 24px, or >= 18.66px and bold >= 700) uses 3.0, normal text uses 4.5
    - Returns `{ pass, fail, skip, total: pass + fail }` — use `pass` as the score (direction: max)
