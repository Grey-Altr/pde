    GREEN phase — implement bin/lib/render-presentation.cjs:

    Create the module following the Section-Based Document Model from RESEARCH.md:

    1. **escHtml(str)** — escape `&`, `<`, `>`, `"`, `'` for safe HTML embedding. Returns empty string for falsy input.

    2. **embedImage(absolutePath)** — read file as base64, return `data:MIME;base64,...` string. Return null if file does not exist. MIME map: png, jpg, jpeg, gif, webp, svg.

    3. **buildTOC(sections)** — generate `<nav class="toc">` with `<a href="#${section.id}">` links for all sections with level <= 2.

    4. **personaDisplayName(slug)** — map slug to display name. Map: `executive-summary` -> `Executive Summary`, `case-study` -> `Case Study / Portfolio Piece`.

    5. **buildExecutiveSummary(ir)** — return section array:
       - `{ id: 'overview', title: 'Project Overview', level: 1 }` — ir.project.name, ir.project.core_value, first 300 chars of ir.project.summary
       - `{ id: 'progress', title: 'Progress', level: 2 }` — ir.phases.completion_pct, completed/total phases and plans
       - `{ id: 'requirements', title: 'Requirements', level: 2 }` — ir.requirements.total, completed, blocked, categories breakdown
       - `{ id: 'blockers', title: 'Blockers & Risks', level: 2 }` — ir.blockers.items + ir.risks.items
       - `{ id: 'decisions', title: 'Key Decisions', level: 2 }` — ir.decisions.items (show source and text)
       - `{ id: 'timeline', title: 'Timeline & Velocity', level: 2 }` — ir.git_velocity, ir.cost_timing
       - `{ id: 'artifacts', title: 'Design Artifacts', level: 2 }` — ir.design_artifacts with base64 embed or "no artifacts" notice
       Every builder function MUST start with sentinel check: `if (irField && irField.unavailable) return '<p class="unavailable">...' + escHtml(irField.reason) + '</p>';`

    6. **buildCaseStudy(ir)** — return section array (problem-approach-outcome-lessons per ROADMAP lock):
       - `{ id: 'problem', title: 'The Problem', level: 1 }` — ir.project.goal context, what challenge was being solved
       - `{ id: 'approach', title: 'Our Approach', level: 2 }` — ir.decisions methodology, phase structure
       - `{ id: 'outcome', title: 'Outcome', level: 2 }` — ir.phases completion, ir.requirements coverage, ir.verification results
       - `{ id: 'lessons', title: 'Lessons Learned', level: 2 }` — ir.decisions + ir.blockers insights
       - `{ id: 'technical', title: 'Technical Decisions', level: 2 }` — ir.decisions filtered to technical choices
       - `{ id: 'artifacts', title: 'Design Evidence', level: 2 }` — same artifact embedding as executive summary
       Same sentinel check pattern for all builders.

    7. **renderHTML(ir, persona, sections)** — template literal producing full HTML document:
       - `<!DOCTYPE html>` with `<html lang="en">`
       - `<meta charset="UTF-8">`, `<meta name="viewport" ...>`
       - `<title>` using ir.project.name and personaDisplayName
       - `<style>` block with PDE design tokens CSS custom properties:
         `--pde-bg: #0d1117`, `--pde-surface: #161b22`, `--pde-border: #30363d`,
         `--pde-text: #e6edf3`, `--pde-text-muted: #8b949e`, `--pde-accent: #58a6ff`,
         `--pde-success: #3fb950`, `--pde-warning: #d29922`, `--pde-danger: #f85149`,
         `--pde-font: -apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif`,
         `--pde-mono: ui-monospace, "Cascadia Mono", monospace`,
         `--pde-radius: 6px`, `--pde-space-sm: 0.5rem`, `--pde-space-md: 1rem`, `--pde-space-lg: 2rem`
       - Full CSS layout rules using these tokens (body, headers, nav.toc, section, table, .unavailable, .doc-header, .doc-footer, img)
       - TOC nav from buildTOC(sections)
       - Body sections with `<section id="${s.id}"><h${s.level}>${escHtml(s.title)}</h${s.level}>${s.content}</section>`
       - Footer with IR metadata (extracted_at, source_hash first 8 chars)
       - ZERO `<script>` tags, ZERO external URLs

    8. **renderMarkdown(ir, persona, sections)** — plain text output:
       - Title line: `# ${ir.project.name} — ${personaDisplayName(persona)}`
       - Blockquote metadata: `> Generated ${ISO date} · IR source hash: ${hash.slice(0,8)}`
       - For each section: ATX heading (`#`.repeat(level)), blank line, content (strip HTML tags for MD), blank line

    9. **render(ir, persona, htmlPath, mdPath)** — orchestrator:
       - Dispatch to persona builder (switch on slug)
       - Call renderHTML + renderMarkdown
       - Size guard: if Buffer.byteLength(html, 'utf-8') > 500 * 1024, log warning (do not fail — truncation is future enhancement)
       - fs.writeFileSync both files
       - Return `{ htmlPath, mdPath, htmlBytes: Buffer.byteLength(html, 'utf-8') }`

    10. **cmdPresentationRender(cwd, persona, htmlPath, mdPath, irFilePath)** — CLI handler:
        - If irFilePath provided and file exists, read and parse JSON
        - Else call `require('./presentation.cjs').buildPresentationIR(cwd)`
        - Call render(ir, persona, htmlPath, mdPath)
        - Output result via `require('./core.cjs').output()`

    module.exports: render, renderHTML, renderMarkdown, buildExecutiveSummary, buildCaseStudy, buildTOC, embedImage, escHtml, personaDisplayName, cmdPresentationRender
