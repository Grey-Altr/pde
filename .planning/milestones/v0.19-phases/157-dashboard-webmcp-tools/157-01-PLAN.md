1. Modify `dashboard/components/providers.tsx` (BRW-01):
   - Add `import { useEffect } from 'react';`
   - Add `import { initializeWebModelContext } from '@mcp-b/global';`
   - Create a `WebMcpInitializer` component (NOT exported — internal only):
     ```typescript
     function WebMcpInitializer() {
       useEffect(() => {
         initializeWebModelContext();
       }, []);
       return null;
     }
     ```
   - Place `<WebMcpInitializer />` inside the Providers tree, BEFORE {children} but inside HotkeysProvider:
     ```typescript
     export function Providers({ children }: { children: React.ReactNode }) {
       return (
         <NuqsAdapter>
           <HotkeysProvider>
             <WebMcpInitializer />
             {children}
           </HotkeysProvider>
         </NuqsAdapter>
       );
     }
     ```
   - CRITICAL: initializeWebModelContext() MUST be inside useEffect to avoid SSR crash (navigator is not defined). The function is idempotent and a no-op in non-browser environments, but the module evaluation path must be safe.

2. Create `dashboard/lib/mcp/use-mcp-client.ts` (BRW-04):
   - File header: `'use client';`
   - Import useState, useCallback from 'react'
   - Export type `McpCallState = 'idle' | 'calling' | 'done' | 'error'`
   - Export interface `UseMcpClientOptions`:
     - `endpoint: string` (e.g. '/api/mcp')
     - `getToken?: () => Promise<string | null>` (Clerk token getter)
   - Export function `useMcpClient({ endpoint, getToken }: UseMcpClientOptions)`:
     - State: `const [state, setState] = useState<McpCallState>('idle')`
     - State: `const [error, setError] = useState<string | null>(null)`
     - `callTool` is a useCallback that:
       a. Sets state to 'calling', clears error
       b. Gets token via getToken() if provided
       c. Builds headers: `Content-Type: application/json`, `Accept: application/json, text/event-stream`
       d. If token exists, adds `Authorization: Bearer ${token}`
       e. Builds JSON-RPC 2.0 body: `{ jsonrpc: '2.0', id: Date.now(), method: 'tools/call', params: { name, arguments: args } }`
       f. Calls `fetch(endpoint, { method: 'POST', headers, body: JSON.stringify(body) })`
       g. If `!res.ok`, throws `new Error('MCP error: ' + res.status)`
       h. Reads Content-Type: if includes 'application/json' -> res.json(); else reads text, finds 'data: ' line, parses JSON after 'data: '
       i. Sets state to 'done', returns result
       j. On catch: sets error message, sets state to 'error', re-throws
     - `callTool` dependency array: `[endpoint, getToken]`
     - Returns `{ callTool, state, error }`
   - MUST NOT import anything from `@modelcontextprotocol/sdk`
   - No session ID tracking (Phase 156 uses stateless mode)
  </action>
