    **Step 2: Create `dashboard/lib/mcp/origin-guard.ts`.**
    Export `ALLOWED_ORIGINS` as a `Set<string>` containing:
    - `process.env.NEXT_PUBLIC_APP_URL` (filtered if undefined)
    - `'http://localhost:3000'`

    Export `validateOrigin(req: Request): Response | null`:
    - Get `origin` from `req.headers.get('origin')`
    - If `origin !== null && !ALLOWED_ORIGINS.has(origin)` return `new Response('Origin not allowed', { status: 403 })`
    - Otherwise return `null`

    This implements the MCP spec MUST requirement: validate Origin on every request type. Null origin is allowed because desktop clients (npx relay, Claude Code CLI) do not send Origin headers.

    **Step 3: Create `dashboard/lib/mcp/tools/index.ts`.**
    Export `registerPipelineTools(server: McpServer): void` as a stub that registers no tools yet (Plan 03 fills this in). Import type `McpServer` from `@modelcontextprotocol/sdk/server/mcp.js`.

    **Step 4: Create `dashboard/lib/mcp/server-factory.ts`.**
    Import type `McpServer` from `@modelcontextprotocol/sdk/server/mcp.js`.
    Import `z` from `zod`.
    Import `registerPipelineTools` from `./tools/index`.

    Export `registerPdeTools(server: McpServer): void` that:
    1. Calls `server.tool('get_project_state', 'Returns current PDE project state from .planning/', {}, async () => ({ content: [{ type: 'text', text: JSON.stringify({ status: 'ok', message: 'PDE project state' }) }] }))`
    2. Calls `registerPipelineTools(server)`

    The function is pure -- it only registers tools. It does NOT create a transport or call `server.connect()`.
