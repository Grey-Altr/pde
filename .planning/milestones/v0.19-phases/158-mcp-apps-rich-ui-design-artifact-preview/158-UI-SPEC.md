## Spacing Scale

Declared values (multiples of 4px — Tailwind v4 default scale):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Compact element spacing, CardContent internal gap |
| md | 16px | Default element spacing, panel body padding |
| lg | 24px | Section padding, artifact viewer inner padding |
| xl | 32px | Layout gaps between viewer sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: none

Note: Phase 158 adds no new interactive surfaces to the dashboard shell. The MCP App HTML panels render inside sandboxed iframes managed by the MCP host (Claude web, VS Code). The iframe HTML uses system defaults (body padding: 1rem = 16px, matching md token). No dashboard layout changes required.

## Typography

All values pre-populated from existing codebase patterns (session-card.tsx, status-badge.tsx, globals.css).

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Muted metadata, artifact path labels, fallback text copy |
| Label | 14px (text-sm) | 600 (semibold) | 1.4 | Badges, status labels, section headings inside iframe viewer |
| Heading | 16px (text-base) | 600 (semibold) | 1.4 | Phase/plan names in session cards (precedent in session-card.tsx `text-base font-semibold`) |
| Mono | 14px (text-sm font-mono) | 400 (regular) | 1.5 | Artifact file paths, resource URIs, tool response text fallbacks |

Font weight constraint: exactly 2 weights — 400 (regular) and 600 (semibold). No other weights.

MCP App iframe HTML typography (artifact-viewer.html):
- Font stack: `system-ui, -apple-system, sans-serif`
- Body: 14px, weight 400, line-height 1.5
- Artifact name heading: 16px, weight 600, line-height 1.4
- Pre/code blocks (artifact content): 13px, font-mono, weight 400, line-height 1.6

## Color

Tokens from globals.css oklch values. Both light and dark modes declared — use CSS variables exclusively, never hard-code hex.

| Role | CSS Variable | Light (oklch) | Dark (oklch) | Usage |
|------|-------------|---------------|--------------|-------|
| Dominant (60%) | `--background` | oklch(1 0 0) — white | oklch(0.145 0 0) — near-black | Page background, iframe viewer background |
| Secondary (30%) | `--card` / `--sidebar` | oklch(1 0 0) / oklch(0.985 0 0) | oklch(0.205 0 0) / oklch(0.205 0 0) | Tool response panels, artifact viewer wrapper card |
| Accent (10%) | `--primary` | oklch(0.205 0 0) — near-black | oklch(0.922 0 0) — near-white | Resource URI chips, "Open preview" badge, active tab indicator |
| Destructive | `--destructive` | oklch(0.577 0.245 27.325) — red | oklch(0.704 0.191 22.216) — red | Error states only: artifact-not-found error, resource read failure |
| Muted | `--muted-foreground` | oklch(0.556 0 0) | oklch(0.708 0 0) | Fallback text copy, secondary metadata, empty state body |

Accent reserved for: resource URI chips (the `ui://pde/[artifact]` badge), the "Preview available" indicator on tool responses, active tab indicator. NOT for generic interactive elements.

MCP App iframe HTML color: use `color-scheme: light dark` with CSS `prefers-color-scheme` media query. Default to white background in iframe (MCP host controls dark mode, not the embedded HTML).

## Copywriting Contract

This phase is primarily a server-side protocol concern (tool handlers + resource registration). The copywriting contract covers: tool response text fallbacks (what stdio clients see), empty states (no artifacts found), and error states (artifact not found / CSP failure).

| Element | Copy |
|---------|------|
| Primary CTA | "Preview Artifact" (tool name visible in MCP Apps UI: `preview_artifact`) |
| Tool response fallback (stdio) | "Design artifact: .planning/design/handoff/{name}. Open in an MCP Apps-capable client to view the rendered preview." |
| Resource URI label | "ui://pde/{artifact}" |
| Empty state heading | "No design artifacts found" |
| Empty state body | "Design artifacts appear here after running /pde:wireframe or /pde:mockup. Run a design workflow command to generate your first artifact." |
| Artifact not found error | "Artifact '{name}' not found. Check .planning/design/handoff/ for available files, or run a design workflow to generate one." |
| Resource read failure error | "Could not load artifact preview. The artifact file may have been moved or deleted." |
| CSP block indicator | Not user-visible — CSP errors appear in browser devtools only. No copy required. |
| Destructive confirmation | None — phase 158 has no destructive actions. All operations are read-only (readOnlyHint: true). |

Tone: factual, tool-oriented. These are developer-facing strings. No marketing language. No emojis. Error copy includes the problem description and next step in one sentence.

## Interaction States

All tool handlers in this phase are read-only. Interaction model:

| State | Visual Treatment |
|-------|-----------------|
| Loading (resource resolving) | Skeleton component, single line, full width of response card |
| Loaded (artifact found) | Card with artifact name as heading, `ui://pde/{artifact}` Badge, Separator, plain text fallback in muted color |
| Empty (no artifacts in directory) | Muted foreground text, empty state copy as defined above |
| Error (file not found) | `--destructive` foreground text, error copy as defined above, no icon |
| Iframe (MCP Apps host) | White background, system-ui font, artifact content in ScrollArea-equivalent pre block |

No hover states, no focus rings, no animations needed for this phase — the rendered UI is inside an MCP host iframe, not a user-navigable surface.

## MCP App HTML Panel Spec

The artifact-viewer iframe HTML (served at `ui://pde/artifact-viewer` and per-artifact at `ui://pde/{artifact}`) must satisfy:

| Property | Value |
|----------|-------|
| DOCTYPE | `<!DOCTYPE html>` |
| charset | UTF-8 |
| viewport | `width=device-width, initial-scale=1` |
| Background | `#ffffff` (light), respects `prefers-color-scheme` for dark: `#1a1a1a` |
| Font | `system-ui, -apple-system, sans-serif` |
| Body padding | `1rem` (16px — matches md token) |
| Artifact name heading | `font-size: 1rem; font-weight: 600; margin-bottom: 0.5rem` |
| Content pre block | `white-space: pre-wrap; word-break: break-word; font-family: monospace; font-size: 0.8125rem; line-height: 1.6; overflow-y: auto; max-height: 60vh` |
| CSP connectDomains | `[process.env.NEXT_PUBLIC_APP_URL]` — must be set in `contents[0]._meta.ui.csp.connectDomains` |
| CSP resourceDomains | `[process.env.NEXT_PUBLIC_APP_URL]` — must be set in `contents[0]._meta.ui.csp.resourceDomains` |
| MIME type | `text/html;profile=mcp-app` — use `RESOURCE_MIME_TYPE` constant, never hard-code |
| Resource URI scheme | `ui://pde/{artifact}` — module-level const, shared between `registerAppTool` and `registerAppResource` calls |
