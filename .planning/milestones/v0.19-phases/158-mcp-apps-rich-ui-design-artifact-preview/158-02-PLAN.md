3. Add helper functions BEFORE the `registerArtifactPreviewTools` export:

   a. `wrapInHtmlShell(title: string, bodyHtml: string): string` — wraps content in the full HTML template from UI-SPEC:
      - DOCTYPE html, charset UTF-8, viewport meta
      - CSS per UI-SPEC MCP App HTML Panel Spec:
        - `color-scheme: light dark`
        - `--bg: light-dark(#fff, #1a1a1a)`, `--fg: light-dark(#1a1a1a, #e8e8e8)`, etc.
        - Font: `system-ui, -apple-system, sans-serif`
        - Body: `max-width: 780px; margin: 0 auto; padding: 1rem`
        - Heading: `font-size: 1rem; font-weight: 600; margin-bottom: 0.5rem`
        - Pre/code: `font-family: ui-monospace, Menlo, Consolas, monospace; font-size: 0.8125rem; line-height: 1.6`
        - Table styles: `border-collapse: collapse; width: 100%` with bordered cells
      - Returns `<!DOCTYPE html><html lang="en"><head>...</head><body><h2>${title}</h2>${bodyHtml}</body></html>`

   b. `renderArtifact(filename: string, raw: string): string` — format-specific rendering:
      - `.html` extension: Pass-through, but replace `<link rel="stylesheet" href="../../assets/tokens.css">` (and variants) with an inlined `<style>` block. Try to read the tokens.css file from the design directory; if not found, strip the link tag. Use regex: `/<link[^>]*href=["'][^"']*tokens\.css["'][^>]*>/gi`
      - `.md` extension: `marked.parse(raw)` (synchronous mode — `marked.parse` returns string). Wrap result in `wrapInHtmlShell(filename, parsedHtml)`.
      - `.json` extension: Pretty-print with `JSON.stringify(JSON.parse(raw), null, 2)`, HTML-escape, wrap in `<pre><code>${escaped}</code></pre>`, then `wrapInHtmlShell(filename, preBlock)`.
      - `.ts`, `.css`, `.csv` extensions: HTML-escape the raw content, wrap in `<pre><code>${escaped}</code></pre>`, then `wrapInHtmlShell(filename, preBlock)`.
      - `.svg` extension: Wrap raw SVG directly in `wrapInHtmlShell(filename, raw)` (SVG is valid HTML).
      - Default: HTML-escape and wrap in pre block via `wrapInHtmlShell`.

   c. `escapeHtml(str: string): string` — replaces `&` with `&amp;`, `<` with `&lt;`, `>` with `&gt;`, `"` with `&quot;`.

   d. `renderErrorHtml(name: string): string` — returns `wrapInHtmlShell('Error', '<p style="color: var(--destructive, #dc2626)">Artifact \'${escapeHtml(name)}\' not found. Check .planning/design/ for available files, or run a design workflow to generate one.</p>')`.

4. Inside `registerArtifactPreviewTools`, AFTER the existing registerAppResource and registerAppTool calls, add the ResourceTemplate registration:

   ```typescript
   // RUI-03: Dynamic artifact resource at ui://pde/{artifact}
   server.registerResource(
     'pde-design-artifact',
     new ResourceTemplate('ui://pde/{artifact}', {
       list: async () => {
         const designDir = path.join(process.cwd(), '.planning', 'design');
         try {
           const entries = await fs.readdir(designDir, { recursive: true });
           const files = entries
             .map(String)
             .filter(f => /\.(html|md|json|ts|svg|css|csv)$/.test(f));
           return {
             resources: files.map(f => ({
               uri: `ui://pde/${encodeURIComponent(f)}`,
               name: f,
               mimeType: RESOURCE_MIME_TYPE,
             })),
           };
         } catch {
           return { resources: [] };
         }
       },
     }),
     {
       title: 'PDE Design Artifact',
       description: 'Renders a design artifact from .planning/design/ as an HTML preview',
       mimeType: RESOURCE_MIME_TYPE,
     },
     async (uri, { artifact }) => {
       const artifactName = decodeURIComponent(String(artifact));
       const designDir = path.join(process.cwd(), '.planning', 'design');
       // Search for the artifact in the design directory tree
       const filePath = path.join(designDir, artifactName);
       try {
         let raw = await fs.readFile(filePath, 'utf-8');
         // For HTML files with external tokens.css link, inline it
         if (artifactName.endsWith('.html') && raw.includes('tokens.css')) {
           try {
             const tokensPath = path.resolve(path.dirname(filePath), '..', '..', 'assets', 'tokens.css');
             const tokensCss = await fs.readFile(tokensPath, 'utf-8');
             raw = raw.replace(/<link[^>]*href=["'][^"']*tokens\.css["'][^>]*>/gi, `<style>${tokensCss}</style>`);
           } catch {
             // tokens.css not found — just strip the link tag
             raw = raw.replace(/<link[^>]*href=["'][^"']*tokens\.css["'][^>]*>/gi, '');
           }
         }
         const html = artifactName.endsWith('.html') ? raw : renderArtifact(artifactName, raw);
         return {
           contents: [{
             uri: uri.href,
             mimeType: RESOURCE_MIME_TYPE,
             text: html,
             _meta: {
               ui: {
                 csp: {
                   connectDomains: [BASE_URL],
                 },
               },
             },
           }],
         };
       } catch {
         return {
           contents: [{
             uri: uri.href,
             mimeType: RESOURCE_MIME_TYPE,
             text: renderErrorHtml(artifactName),
             _meta: {
               ui: {
                 csp: {
                   connectDomains: [BASE_URL],
                 },
               },
             },
           }],
         };
       }
     },
   );
   ```

Key constraints from research:
- ResourceTemplate `list` callback is used for resource discovery by AI clients
- Read callback `uri` param is a URL object — use `uri.href` for the contents URI
- `{artifact}` template parameter comes as a string in the params object
- HTML artifacts may reference `../../assets/tokens.css` — inline it (Gotcha from deep research)
- Mermaid CDN loading deferred to future phase (too heavy for Phase 158 inline approach)
- Use `marked.parse()` synchronous API (marked v17 supports sync by default)
- `decodeURIComponent` on artifact name since it's URL-encoded in the URI
