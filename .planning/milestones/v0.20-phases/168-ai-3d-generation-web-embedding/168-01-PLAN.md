    1. Install new dependencies:

       npm install @huggingface/inference @gradio/client @gltf-transform/cli @gltf-transform/core

    2. Create `bin/lib/3d-pipeline/assets.cjs` (per TRD-08) following the image-pipeline/assets.cjs pattern:
       - `THREE_D_DIR = path.join(process.cwd(), '.planning/design/3d')`
       - `save3DAsset({ slug, glbBuffer, meta, assetsDir })`:
         - mkdirSync(baseDir, { recursive: true })
         - Write `{slug}-{timestamp}.glb` from glbBuffer
         - Compute sha256 hash of glbBuffer
         - Write `{slug}-{timestamp}.meta.json` with: `{ source_model, input_type, input_hash, timestamp (ISO), file_size (bytes), vertex_count, slug, glb_path (relative) }`
         - Return `{ glbPath, metaPath, meta }`
       - `list3DAssets({ assetsDir })`:
         - Reads all `.meta.json` files in baseDir
         - Returns JSON array of metadata objects with added `glb_file` field (from meta filename with .meta.json replaced by .glb)
       - `module.exports = { save3DAsset, list3DAssets, THREE_D_DIR }`

    3. Create `bin/lib/3d-pipeline/optimize.cjs` (per TRD-03):
       - `optimizeGLB({ inputPath, outputPath, textureMaxSize = 1024 })`:
         - Resolve gltf-transform binary: try `path.join(process.cwd(), 'node_modules/.bin/gltf-transform')` first, fall back to `npx --yes @gltf-transform/cli` (per Pitfall 7)
         - Step 1: spawnSync draco compression: `[binPath, 'draco', inputPath, outputPath, '--method', 'edgebreaker']`
         - Step 2: spawnSync texture resize: `[binPath, 'resize', outputPath, outputPath, '--width', String(textureMaxSize), '--height', String(textureMaxSize)]`
         - Check status !== 0 for each step, throw Error with stderr
         - Return `{ outputPath, sizeMB: (fs.statSync(outputPath).size / 1e6).toFixed(2) }`
       - `inspectGLB({ glbPath })`:
         - spawnSync `[binPath, 'inspect', glbPath, '--format', 'json']`
         - Parse JSON from stdout, extract vertex_count from mesh data
         - If inspect fails or --format json not supported, return `{ vertex_count: 0, file_size: fs.statSync(glbPath).size }`
       - `module.exports = { optimizeGLB, inspectGLB }`

    4. Create `bin/lib/3d-pipeline/embed.cjs` (per TRD-04, TRD-05):
       - `generateEmbed({ glbPath, slug, cameraOrbit = '45deg 75deg 2m' })`:
         - Build model-viewer snippet using CDN URL `https://ajax.googleapis.com/ajax/libs/model-viewer/4.0.0/model-viewer.min.js`
         - Include attributes: `src`, `ar`, `ar-modes="webxr scene-viewer quick-look"`, `camera-controls`, `camera-orbit`, `auto-rotate`, `shadow-intensity="1"`, `style="width:100%;height:500px"`
         - Do NOT include `ios-src` — model-viewer auto-generates USDZ on iOS (per research: skip server-side USDZ)
         - Build self-contained HTML page wrapping the snippet with DOCTYPE, charset, title using slug
         - Write HTML to `{assetsDir}/{slug}-embed.html` where assetsDir defaults to THREE_D_DIR
         - Return `{ snippet, html, embedPath }`
       - Accept optional `assetsDir` param for test isolation
       - `module.exports = { generateEmbed }`

    All modules: 'use strict', CJS pattern, require('fs'), require('path'), require('child_process') as needed.
