2. Create `bin/lib/cli-anything/codegen.cjs`:

The module has three main functions:

**`jsonSchemaToZod(schema, depth = 0)`** — Recursively walks a JSON Schema object and returns a Zod builder call string. Rules:
- If `!schema` or `typeof schema !== 'object'` or `depth > 8`: return `'z.unknown()'`
- `type: 'string'` with `enum`: return `z.enum([${schema.enum.map(v => JSON.stringify(v)).join(', ')}])` — MUST be array form, NOT object form (Zod v4 requirement)
- `type: 'string'`: return `z.string()`, append `.describe(${JSON.stringify(schema.description)})` if description exists
- `type: 'number'` or `type: 'integer'`: return `z.number()`, append `.describe()` if description
- `type: 'boolean'`: return `z.boolean()`
- `type: 'array'`: return `z.array(${jsonSchemaToZod(schema.items || {}, depth + 1)})`
- `type: 'object'`: if no properties return `z.record(z.unknown())`; otherwise build `z.object({ fieldName: zodExpr, ... })` where each field gets `.optional()` if not in `schema.required` array
- `enum` without type: return `z.enum([...])` with array form
- Default: return `z.unknown()`

**`generateToolSource(capabilities, meta)`** — Takes capabilities array and meta object, returns a complete `.ts` file string. Structure:
```
// Auto-generated by /pde:ingest
// Source: {meta.source}
// Generated: {meta.generatedAt}
// WARNING: stub execute functions — customize before production use

import { tool } from 'ai';
import { z } from 'zod';

export const {capName} = tool({
  description: {JSON.stringify(cap.description)},
  inputSchema: {jsonSchemaToZod(cap.inputSchema)},
  execute: async (input) => {
    {generateExecuteBody(cap, meta)}
  },
});
```

For execute body:
- If `meta.type === 'openapi'` and `cap.method` and `cap.path`: generate fetch call with correct method and path, using `JSON.stringify(input)` as body for POST/PUT/PATCH
- If `meta.type === 'graphql'`: generate fetch POST with GraphQL query string using cap.name
- If `meta.type === 'mcp'`: generate a comment `// Use MCP client.callTool('${cap.name}', input)`
- Default: generate `return { result: 'stub — implement me' };`

Capability names are sanitized to valid JS identifiers: replace non-alphanumeric with _, ensure starts with letter, camelCase.

**`typeCheckGeneratedFile(outputDir)`** — Runs tsc --noEmit on the output directory. Uses `require('child_process').execFileSync` (NOT exec — safer, no shell injection). The tsc binary path is `path.join(__dirname, '../../../packages/pde-mcp-server/node_modules/.bin/tsc')`. Creates a `tsconfig.validate.json` in outputDir with `{ compilerOptions: { target: "ES2022", module: "ESNext", moduleResolution: "bundler", strict: true, skipLibCheck: true }, include: ["tools.ts"] }`. Returns `{ ok: true }` on success, `{ ok: false, output: string }` on tsc error.

**`generateTools(model, outputDir)`** — High-level function called by ingest.cjs. Generates tools.ts source string via generateToolSource, writes tsconfig.validate.json and tools.ts to outputDir, runs typeCheckGeneratedFile, reports result.

All exported: `module.exports = { generateTools, generateToolSource, jsonSchemaToZod, typeCheckGeneratedFile }`.
