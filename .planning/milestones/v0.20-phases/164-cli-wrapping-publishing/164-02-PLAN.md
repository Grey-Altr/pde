  <behavior>
    - parseSubcommands(helpText) extracts {name, description} pairs from two-column format
    - parseSubcommands skips ALL_CAPS section headers (e.g., COMMANDS:, OPTIONS:)
    - parseSubcommands skips lines starting with - or -- (flags)
    - parseSubcommands skips lines with special chars (:, (, )) in first token
    - parseFlags(helpText) extracts {long, short, arg, description} for each flag
    - spawnHelpText(binary, cmdPath) uses spawnSync with timeout:5000
    - spawnHelpText returns stdout || stderr (handles stderr-only CLIs)
    - discoverCapabilities(binary) recursively discovers subcommands up to depth 3
    - discoverCapabilities creates at least one fallback capability when no subcommands found
  </behavior>
  <action>
    Create bin/lib/cli-anything/help-parser.cjs as a CJS module.

    **Exports:** parseSubcommands, parseFlags, spawnHelpText, discoverCapabilities

    **spawnHelpText(binary, cmdPath):**
    - Uses `spawnSync(binary, [...cmdPath, '--help'], { encoding: 'utf8', timeout: 5000 })`
    - Returns `(result.stdout || result.stderr || '').trim()`
    - Do NOT check exit code -- many CLIs return non-zero for --help

    **parseSubcommands(helpText):**
    - Split by newlines, apply regex: `/^  {0,4}(\w[-\w]*)  {2,}(.+)/`
    - Skip lines matching `/^[A-Z][A-Z\s]+:/` (section headers like COMMANDS:)
    - Skip lines matching `/^\s*-/` (flags)
    - Skip lines where first token contains `:`, `(`, `)`
    - Return array of `{ name, description }` objects

    **parseFlags(helpText):**
    - Match `/^\s+(-\w)?(?:,\s*)?(-{1,2}[\w-]+)(?:\s+<([^>]+)>)?\s{2,}(.+)?/`
    - Return array of `{ short, long, arg, description }` objects

    **discoverCapabilities(binary, prefix=[], depth=0):**
    - If depth > 3, return []
    - Call spawnHelpText(binary, prefix)
    - Parse subcommands and flags
    - For each subcommand: build a CapabilitySchema-shaped object with:
      - name: prefix.concat(sub.name).join('_') (e.g., "git_commit")
      - description: sub.description
      - inputSchema: { type: 'object', properties: { useJson: { type: 'boolean', description: 'Append --json flag' }, ...flagProperties } }
      - outputSchema: null
      - method: null
      - path: prefix.concat(sub.name).join(' ') (e.g., "git commit")
      - extensions: { subcommandPath: prefix.concat(sub.name) }
    - Recurse: for each subcommand, check if IT has subcommands (depth+1)
    - **Fallback:** If no subcommands found at depth 0, create single capability for binary itself with description from help text (truncated to 1000 chars)

    **Critical:** Use `require('child_process').spawnSync` -- NOT exec, NOT spawn. Array args form prevents shell injection.
  </action>

  <action>
    Create bin/lib/cli-anything/server-gen.cjs as a CJS module.

    **Exports:** generateServerSource, writeServer

    **generateServerSource(capabilities, meta, sdkBasePath):**
    Returns a string of valid JavaScript (CJS) that:

    1. Header comment: `// Auto-generated by /pde:wrap` with binary path and generation timestamp
    2. `'use strict';`
    3. Requires: path, child_process.spawnSync
    4. SDK_BASE = the passed sdkBasePath (JSON.stringify for safe embedding)
    5. McpServer require from `path.join(SDK_BASE, 'server/mcp.js')`
    6. StdioServerTransport require from `path.join(SDK_BASE, 'server/stdio.js')`
    7. BINARY = meta.source (JSON.stringify)
    8. DRY_RUN = process.argv.includes('--dry-run')
    9. `const server = new McpServer({ name: meta.source, version: '1.0.0' });`
    10. For each capability: `server.registerTool(cap.name, { description, inputSchema, annotations: { readOnlyHint: false } }, async (input) => { ... })`

    **Tool handler body (per capability):**
    ```
    const args = [...subcommandPath]; // from cap.extensions.subcommandPath or cap.path.split(' ').slice(1)
    if (input.useJson) args.push('--json');
    // Append other flag args from input (skip useJson)
    for (const [key, val] of Object.entries(input)) {
      if (key === 'useJson') continue;
      if (val !== undefined && val !== null && val !== false) {
        args.push('--' + key);
        if (val !== true) args.push(String(val));
      }
    }
    if (DRY_RUN) {
      return { content: [{ type: 'text', text: JSON.stringify({ dryRun: true, command: [BINARY, ...args] }) }] };
    }
    const r = spawnSync(BINARY, args, { encoding: 'utf8', timeout: 30000 });
    let data;
    try { data = JSON.parse(r.stdout); } catch { data = { stdout: (r.stdout||'').trim(), stderr: (r.stderr||'').trim(), exitCode: r.status ?? -1 }; }
    return { content: [{ type: 'text', text: JSON.stringify(data) }] };
    ```

    11. Main function: `async function main() { const transport = new StdioServerTransport(); await server.connect(transport); }`
    12. `main().catch(err => { process.stderr.write(err.message + '\\n'); process.exit(1); });`

    **inputSchema generation:** For each capability, convert cap.inputSchema to a JSON Schema object. Always include `useJson: { type: 'boolean', description: 'Append --json flag to command' }` in properties.

    **writeServer(outputDir, capabilities, meta, projectRoot):**
    - Compute sdkBasePath as `path.join(projectRoot, 'packages/pde-mcp-server/node_modules/@modelcontextprotocol/sdk/dist/cjs')`
    - Call generateServerSource to get the source string
    - Create outputDir if needed (fs.mkdirSync recursive)
    - Write source to `path.join(outputDir, 'server.cjs')`
    - Return the output path

    **CRITICAL:** All paths in generated server.cjs must be absolute. Use JSON.stringify for safe string embedding. Use spawnSync array form (no shell: true) to prevent injection.
