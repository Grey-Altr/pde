  <behavior>
    - computePhash(buffer): 32x32 grayscale via Sharp, separable 2D DCT, top-left 8x8, median threshold -> 64-bit array
    - hammingDistance(h1, h2): count differing bits
    - classifyChange(dist): 0=unchanged, 1-5=minor, 6-15=significant, 16+=major; score=Math.round((dist/64)*100)
    - listBranchImages(branch, cwd): git ls-tree filtered to png/jpg/jpeg/gif/webp
    - readFileFromBranch(branch, path, cwd): git show with encoding:'buffer', null on missing
    - runVisualDiff({ branchA, branchB, assetsDir, cwd }): full pipeline producing MD + JSON report
  </behavior>
  <action>
    Create `bin/lib/image-pipeline/visual-diff.cjs` as a CommonJS module (matching all other image-pipeline modules).

    **computePhash(imageBuffer):**
    - `sharp(imageBuffer).resize(32, 32).grayscale().raw().toBuffer({ resolveWithObject: true })`
    - Separable 2D DCT-II: row DCTs on all 32 rows, then column DCTs on first 8 columns, extract top-left 8x8 = 64 coefficients
    - dct1d function: `sum * (k === 0 ? Math.sqrt(1/N) : Math.sqrt(2/N))` normalization
    - Precompute column DCTs for columns 0-7 only (optimization)
    - Sort 64 values, find median = (sorted[31]+sorted[32])/2, threshold: v > median ? 1 : 0
    - Return 64-element array of 0s and 1s

    **hammingDistance(h1, h2):** Reduce counting bit differences.

    **classifyChange(dist):**
    - score = Math.round((dist / 64) * 100)
    - tier: 0 = 'unchanged', 1-5 = 'minor', 6-15 = 'significant', 16+ = 'major'
    - Return { tier, score }

    **listBranchImages(branch, cwd):**
    - spawnSync('git', ['ls-tree', '-r', '--name-only', branch], { encoding: 'utf8', cwd })
    - Throw on status !== 0 with informative error including branch name and "did you mean to run git fetch first?"
    - Filter lines by IMAGE_EXTENSIONS regex /\.(png|jpg|jpeg|gif|webp)$/i
    - Return Set of paths

    **readFileFromBranch(branch, filePath, cwd):**
    - spawnSync('git', ['show', `${branch}:${filePath}`], { encoding: 'buffer', cwd, maxBuffer: 50*1024*1024 })
    - Return null if status !== 0
    - Check for LFS pointer: if buffer.toString('utf8', 0, 40).startsWith('version https://git-lfs') -> return null and log warning
    - Return buffer

    **runVisualDiff({ branchA, branchB, assetsDir, cwd }):**
    1. List images from both branches via listBranchImages
    2. Compute set intersection/difference:
       - both = intersection(setA, setB) -> candidates for changed/unchanged
       - newAssets = setB - setA (only in branch B)
       - deletedAssets = setA - setB (only in branch A)
    3. For each path in both: read buffers from both branches, computePhash each, hammingDistance, classifyChange
       - Wrap computePhash in try/catch; on error classify as { status: 'error', error: err.message }
    4. Build assets array with { path, status, tier, score, hammingDistance } for changed; { path, status: 'unchanged' } for unchanged; { path, status: 'new' } for new; { path, status: 'deleted' } for deleted
    5. Build summary object: { total, unchanged, minor, significant, major, new, deleted }
    6. Generate timestamp: new Date().toISOString()
    7. Write JSON sidecar: { branchA, branchB, generatedAt, summary, assets } to `${assetsDir}/visual-diff-${Date.now()}.json`
    8. Write Markdown report to `${assetsDir}/visual-diff-${Date.now()}.md` following the format in RESEARCH.md Pattern 4
    9. Return { summary, reportPath, jsonPath, assets }

    **module.exports:** { computePhash, hammingDistance, classifyChange, listBranchImages, readFileFromBranch, runVisualDiff }

    **Edge cases per RESEARCH.md:**
    - Use spawnSync with array args (never shell interpolation) for branch names with slashes
    - Process images sequentially (not all in memory at once)
    - LFS pointer detection before Sharp processing
    - try/catch around computePhash per file (skip corrupted files)
  </action>
