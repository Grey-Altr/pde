    - `const { FFMPEG, saveVideoAsset, resolveResolution } = require('./assets.cjs');`
    - `async function recordUIInteraction({ url, slug, resolution = '1920x1080', durationMs = 5000, assetsDir })`:
      - `const { width, height } = resolveResolution(resolution);`
      - Launch browser headless, create context with `recordVideo: { dir: os.tmpdir(), size: { width, height } }` and `viewport: { width, height }`
      - Navigate to url with `waitUntil: 'networkidle'`
      - `await page.waitForTimeout(durationMs);`
      - Save video ref BEFORE close: `const video = page.video();`
      - `await context.close(); await browser.close();`
      - `const webmPath = await video.path();` (CRITICAL: after context.close per Pitfall 1)
      - Convert WebM to MP4: `execFileSync(FFMPEG, ['-i', webmPath, '-c:v', 'libx264', '-preset', 'fast', '-crf', '23', '-s', '${width}x${height}', '-y', mp4Path])`
      - Call `saveVideoAsset({ slug, mp4Path, dimensions: { width, height }, source: 'playwright-record', params: { url, durationMs, resolution }, assetsDir })`
      - Clean up webmPath temp file
      - Return `{ path, meta }`
    - Export: `{ recordUIInteraction }`

    **assemble.cjs** (VID-02):
    - `const { FFMPEG } = require('./assets.cjs');`
    - `function getClipDuration(clipPath)` — use ffprobe (bundled with ffmpeg-static package or from `ffprobe-static` if needed; check `require('ffmpeg-static').replace('ffmpeg', 'ffprobe')` or use `-i clip -f null -` stderr parse). Simplest: `execFileSync(FFMPEG, ['-i', clipPath, '-f', 'null', '-'], { stdio: ['pipe', 'pipe', 'pipe'] })` and parse "Duration: HH:MM:SS.ms" from stderr. Export for testing.
    - `function assembleClips({ clips, outputPath, transition, transitionDur = 1 })`:
      - If no transition or transition === 'none': write concat list to temp file, run `execFileSync(FFMPEG, ['-f', 'concat', '-safe', '0', '-i', listPath, '-c', 'copy', '-y', outputPath])`, clean up list file
      - If transition === 'crossfade': for 2 clips, compute offset = duration_of_clip_a - transitionDur, run xfade filter. For N clips, chain xfade filters in filter_complex. Use re-encode (`-c:v libx264 -preset fast`).
    - Export: `{ assembleClips, getClipDuration }`

    **caption.cjs** (VID-06):
    - `const { FFMPEG } = require('./assets.cjs');`
    - `function jsonToSrt(captions)` — convert `[{start, end, text}]` to SRT format string. Time format: `HH:MM:SS,mmm`. Export for unit testing.
    - `function captionVideo({ inputPath, outputPath, srt, captions, fontSize = 24, fontColor = 'white', position = 'bottom-center' })`:
      - If `srt` provided (string path): use it directly
      - If `captions` provided (JSON array): write `jsonToSrt(captions)` to temp `.srt` file
      - Run `execFileSync(FFMPEG, ['-i', inputPath, '-vf', 'subtitles=${srtPath}:force_style=Fontsize=${fontSize},PrimaryColour=&H00FFFFFF,FontName=Arial', '-c:a', 'copy', '-y', outputPath])`
      - Clean up temp SRT if created
      - Return outputPath
    - Export: `{ captionVideo, jsonToSrt }`
