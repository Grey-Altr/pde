   - `const VIEWPORT_PRESETS = { desktop: { width: 1440, height: 900 }, tablet: { width: 768, height: 1024 }, mobile: { width: 375, height: 812 } }`
   - `async function captureScreenshot({ url, viewport, slug, outputDir, format = 'png', timeout = 30000 })`
   - Resolve viewport: if string, lookup in VIEWPORT_PRESETS. If object `{ width, height }`, use directly. If `WxH` string pattern, parse to numbers.

   - ALWAYS close browser in a finally block.
   - Call `saveAsset({ type: 'screenshot', slug, buffer, dimensions: viewport, params: { url, viewport: viewportName, format }, source: 'playwright' })`.
   - Return `{ buffer, path, meta }`.
   - `module.exports = { captureScreenshot, VIEWPORT_PRESETS }`

   - Load `templates/mockup-frames/frames.json` for viewport rectangles.
   - Resolve frame PNG path: `templates/mockup-frames/${frame}.png`.
   - Use Sharp to resize screenshot to fit viewportRect (width x height), then composite onto frame PNG at (top, left).
   - Save via `saveAsset({ type: 'mockup', slug, buffer, dimensions, params: { frame, screenshotPath }, source: 'sharp-composite' })`.
   - Return `{ buffer, path, meta }`.
   - `module.exports = { generateMockup }`

    - Test REMBG-4: loadUsage() resets count to 0 when stored month differs from current month
    - Test REMBG-5: removeBackground() increments usage count after successful API call (mock fetch)
    - Test REMBG-6: removeBackground() calls remove.bg API with correct URL, X-Api-Key header, and multipart body (mock fetch)
  </behavior>
  <action>
1. Create `bin/lib/image-pipeline/rembg.cjs`:
   - Constants: `USAGE_PATH = path.join(process.cwd(), '.planning/cli-anything/removebg-usage.json')`, `MONTHLY_LIMIT = 50`, `WARN_THRESHOLD = 40`.
   - `function loadUsage()` — read JSON file, compare stored `month` (YYYY-MM) to current. If different, return `{ month: currentMonth, count: 0 }`. If file missing, return fresh `{ month, count: 0 }`.
   - `function saveUsage(usage)` — write JSON to USAGE_PATH, creating directory if needed.
   - `async function removeBackground({ inputPath, slug, outputDir })`:
     a. Check `process.env.REMOVEBG_API_KEY` — if not set, `console.warn('[rembg] REMOVEBG_API_KEY not set — skipping background removal')` and return null.
     b. Load usage. If `count >= MONTHLY_LIMIT`, throw Error with message including limit.
     c. If `count >= WARN_THRESHOLD`, `console.warn` with current count.
     d. Read input file as Buffer.
     e. Use native `fetch()` to POST to `https://api.remove.bg/v1.0/removebg`:
        - Create FormData (use Node.js built-in `new FormData()` + `new Blob()`).
        - Append `image_file` as Blob from buffer, append `size: 'auto'`.
        - Headers: `{ 'X-Api-Key': apiKey }` (do NOT set Content-Type — fetch handles multipart boundary).
     f. Check `response.ok`. If 429, throw rate limit error. If other non-ok, call `response.text()` for error detail and throw.
     g. Get result as `Buffer.from(await response.arrayBuffer())`.
     h. Increment usage count, save.
     i. Call `saveAsset({ type: 'rembg', slug, buffer, dimensions: null, params: { inputPath }, source: 'remove.bg' })`.
     j. Return `{ buffer, path, meta }`.
   - `module.exports = { removeBackground, loadUsage, MONTHLY_LIMIT, WARN_THRESHOLD }`

2. Create `tests/phase-165/rembg.test.mjs`:
   - Mock `global.fetch` to simulate remove.bg API responses.

   - Use `mkdtempSync` for isolated usage file and output.
   - Test all 6 behaviors from the behavior block.
   - Test that API key is NOT stored in metadata sidecar (security check).
