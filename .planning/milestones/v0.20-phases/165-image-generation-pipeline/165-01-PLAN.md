2. Download Inter-Regular.ttf font file to `bin/lib/image-pipeline/fonts/Inter-Regular.ttf`:
   ```bash
   mkdir -p bin/lib/image-pipeline/fonts
   curl -L -o bin/lib/image-pipeline/fonts/Inter-Regular.ttf \
     "https://github.com/google/fonts/raw/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf"
   ```
   If the variable font URL fails, try: `https://github.com/rsms/inter/raw/master/docs/font-files/Inter-Regular.ttf`
   Verify the file is >100KB and is a valid font (not HTML error page).

3. Create `bin/lib/image-pipeline/assets.cjs` — the shared asset storage module:
   - `saveAsset({ type, slug, buffer, dimensions, params, source })` — writes PNG to `.planning/design/assets/{type}/{slug}-{timestamp}.png`, writes `.meta.json` sidecar with `{ type, source, dimensions, timestamp (ISO), params, hash (SHA-256 of buffer) }`. Returns `{ path, metaPath, meta }`.
   - `listAssets({ type, assetsDir })` — reads all `.meta.json` files from `.planning/design/assets/` (optionally filtered by type). Returns JSON array with each entry containing all meta fields plus `file` (PNG filename) and `dir` (type subdirectory).
   - `ASSETS_DIR` constant: `path.join(process.cwd(), '.planning/design/assets')`
   - Use `crypto.createHash('sha256')` for hash, `Date.now()` for timestamp.
   - `module.exports = { saveAsset, listAssets, ASSETS_DIR }`

4. Create `tests/phase-165/assets.test.mjs`:
   - Test `saveAsset()`: pass a fake PNG buffer, verify PNG file + .meta.json are written to a temp dir, verify meta contains all required fields (type, source, dimensions, timestamp, params, hash).
   - Test `listAssets()`: save 2 assets of different types, verify list returns both; filter by type returns 1.
   - Test `listAssets()` on empty directory returns `[]`.
   - Use `mkdtempSync` for fs isolation, mock `process.cwd()` or pass `assetsDir` param.
  </action>

1. Create `bin/lib/image-pipeline/templates/og-default.cjs`:
   - Export `ogDefault({ title, description, brandColor })` returning Satori object-literal element tree.
   - Default brandColor: '#6366f1' (indigo).
   - Layout: full-bleed background, title at 64px white bold, description at 28px white 80% opacity, bottom-aligned with 60px padding.
   - `module.exports = { ogDefault }`

2. Create `bin/lib/image-pipeline/templates/social-default.cjs`:
   - Export `socialDefault({ title, description, width, height, brandColor })` returning Satori object-literal element tree.
   - Similar layout to OG but accepts width/height for platform-specific sizing.
   - `module.exports = { socialDefault }`

3. Create `bin/lib/image-pipeline/og.cjs`:
   - `async function generateOgImage({ title, description, slug, templateFn, outputDir })`
   - Import Satori via `const { default: satori } = require('satori')` (per research — CJS interop).
   - Import `const { Resvg } = require('@resvg/resvg-js')`.
   - Load Inter-Regular.ttf from `path.join(__dirname, 'fonts/Inter-Regular.ttf')` via `fs.readFileSync`.
   - If no `templateFn` provided, default to `require('./templates/og-default.cjs').ogDefault`.
   - Generate SVG via `satori(element, { width: 1200, height: 630, fonts: [...] })`.
   - Rasterize via `new Resvg(svg, { fitTo: { mode: 'width', value: 1200 }, font: { loadSystemFonts: false } }).render().asPng()`.
   - If `outputDir` provided, call `saveAsset({ type: 'og', slug, buffer: pngBuffer, dimensions: { width: 1200, height: 630 }, params: { title, description }, source: templateFn.name || 'ogDefault' })` from assets.cjs.
   - Return `{ buffer: pngBuffer, path, meta }`.
   - `module.exports = { generateOgImage }`

4. Create `bin/lib/image-pipeline/social.cjs`:
   - `const SOCIAL_SIZES = { twitter: { width: 1200, height: 628 }, linkedin: { width: 1200, height: 627 }, facebook: { width: 1200, height: 630 } }`
   - `async function generateSocialCards({ title, description, slug, templateFn, outputDir })`
   - Default templateFn to `require('./templates/social-default.cjs').socialDefault`.
   - Loop over SOCIAL_SIZES entries. For each platform:
     - Call templateFn with { title, description, width, height }.
     - Satori render at platform-specific width/height.
     - Resvg rasterize.
     - Save with slug suffix: `${slug}-${platform}` (e.g., `my-product-twitter`).
     - Type in meta: 'social', add `platform` to params.
   - Return array of 3 results.
   - `module.exports = { generateSocialCards, SOCIAL_SIZES }`
