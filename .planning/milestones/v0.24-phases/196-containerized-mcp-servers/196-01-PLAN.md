<objective>
Add per-server Docker container support to mcp-bridge.cjs APPROVED_SERVERS and extend the probe/degrade contract to account for container startup latency.

Purpose: INF-04 requires each stdio MCP server to run in its own Docker container with a pinned runtime. INF-05 requires probe timeouts to extend by container startup time so probes do not fire degraded state during normal cold starts.
Output: Updated mcp-bridge.cjs with container blocks, three new exported functions, and comprehensive unit tests.
</objective>

       `isDockerAvailable()` — async, checks cache first, then tries `new Dockerode().ping()`. If Dockerode is null (require failed), sets cache to false. Cache result for process lifetime.

       `getInstallCmd(serverKey, dockerAvailable)` — sync. Looks up server in APPROVED_SERVERS || DYNAMIC_SERVERS. If dockerAvailable && server.container exists, returns `claude mcp add ${serverKey} -- docker run --rm -i ${server.container.image} ${server.container.cmd.join(' ')}`. Otherwise returns server.installCmd. Returns null if server not found.

       `getProbeTimeoutMs(serverKey, dockerAvailable)` — sync. Looks up server. base = server.probeTimeoutMs || 10000. If dockerAvailable && server.container, returns base + container.startupMs. Otherwise returns base. Returns 10000 default for unknown servers.
