   - async _poll(): try/catch around execCommand('claude task status ' + taskId + ' --json'). Parse JSON. Call this._onLine({ event_type, session_id, ts, cloud_status }). If status !== 'running', call this.stop(). In catch: emit cloud_error event AND call this.stop() (CRITICAL -- prevents infinite error loop per Pitfall 5)
   - Event shapes: { event_type: 'cloud_heartbeat', session_id, ts, cloud_status: 'running' }, { event_type: 'session_end', ... }, { event_type: 'cloud_error', ..., error: err.message }

3. spawnCloudSession function: (opts) where opts has { sessionId, phase, plan, cloudConfig, onLine, onExit, _deps }.
   - Extract execCommand from opts._deps
   - Declare let poller = null in outer scope
   - Async IIFE: build prompt string, call execCommand('claude task start --remote "' + prompt + '"') to get taskId
   - Create CloudPoller with opts.cloudConfig.poll_interval or 5000
   - CloudPoller onLine callback: call opts.onLine(opts.sessionId, event), then if event.event_type === 'session_end' call opts.onExit(opts.sessionId, 0), if cloud_error call opts.onExit(opts.sessionId, 1)
   - Async IIFE catch: emit cloud_error system event via opts.onLine, call opts.onExit(sessionId, 1)
   - Return { kill: () => { if (poller) poller.stop(); } } synchronously

4. module.exports: { CloudPoller, spawnCloudSession }

- claude task start --remote does NOT exist in current CLI (v2.1.87) -- spawnCloudSession catches failure gracefully per Pitfall 2
- Use 'use strict'; at top (project convention)
