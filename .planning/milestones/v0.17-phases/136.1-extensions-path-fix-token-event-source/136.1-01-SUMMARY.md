# Phase 136.1 Plan 01: Extensions Path Fix & Token Event Source Summary

Fix WireEnvelope field path mismatch in three dashboard consumers (phase_name/plan_name from top-level, not empty extensions sub-object) and add SubagentStop transcript-based token_usage event emission for CostMeter data.

## What Was Built

### Task 1: Fix extensions path in deriveProgress, ingest route, session-detail-client (TDD)

**Bug:** Three dashboard consumers read `extensions?.phase_name` — but `extensions` is always `{}` empty because `event-bus.cjs` spreads PDE payload fields to the top-level envelope, not into `extensions`. Phase/plan names were always empty in the dashboard.

**Fix:** Cast `WireEnvelope` to `Record<string, unknown>` and read from top-level fields — the same pattern already used correctly in `derive-cost.ts`.

- `dashboard/lib/derive-progress.ts`: Replace extensions sub-object read with `payload.phase_name` / `payload.plan_name`, add `payload.plan_id` fallback
- `dashboard/app/api/ingest/route.ts`: Add `lastEventPayload` cast, read top-level `phase_name`/`plan_name` for Redis hset
- `dashboard/app/sessions/[id]/session-detail-client.tsx`: Replace `ext?.phase_name` with `evPayload.phase_name`, add `plan_id` fallback for plan display
- `derive-progress.test.ts`: Updated all fixtures from `extensions: { phase_name }` to top-level `{ phase_name }` as any; added plan_id fallback test and plan_name preference test
- `ingest.test.ts`: Added Test 9 verifying hset receives phase from top-level field

57 dashboard tests pass (up from 54 — 3 new test cases added).

### Task 2: Add token_usage event emission in SubagentStop hook handler

**Bug:** `deriveCost()` correctly reads `input_tokens`/`output_tokens` from top-level envelope fields, but no PDE event type ever emits these fields. Token costs were always $0.

**Fix:** Added `sumTranscriptTokens(transcriptPath)` to `hooks/emit-event.cjs` that reads the subagent's JSONL transcript, sums `input_tokens` and `output_tokens` from all `type=assistant` turns, then emits a `token_usage` event via `pde-tools.cjs event-emit` before the main `subagent_stop` event.

Error handling: file read errors return zeros; JSONL parse errors skip the line; spawnSync errors are swallowed. Hook exit code is never affected.

### Task 3: Integration tests for field path fix and token emission

- `tests/phase-136.1/extensions-path-fix.test.ts`: Verifies `extensions` sub-object is empty and `phase_name`/`plan_id` are at the top level
- `tests/phase-136.1/token-event-emission.test.ts`: Verifies transcript parsing sums tokens correctly, handles missing file, malformed JSONL, and cache fields without double-counting

6 integration tests added, all passing.
