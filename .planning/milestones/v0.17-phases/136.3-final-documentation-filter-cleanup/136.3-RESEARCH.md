## Common Pitfalls

### Pitfall 1: Editing SC-2/SC-3/SC-4 items that are already correct
**What goes wrong:** Plan tasks duplicate work that 136.2 already completed, risk corrupting files with correct content.
**Why it happens:** Audit document lists these as tech_debt but was written before 136.2 closed.
**How to avoid:** Verify each criterion with a grep before editing. If the target state is already present, skip the edit. Tasks should use `<automated>` verify commands that check current state, not blindly write.
**Warning signs:** Plan task descriptions that say "add requirements-completed to 134-01-SUMMARY.md frontmatter" — this is already done.

### Pitfall 2: Removing `as const` from EVENT_FILTER_GROUPS
**What goes wrong:** `FilterGroup = keyof typeof EVENT_FILTER_GROUPS` loses narrowing; all filter group comparisons become `string` instead of a union literal type.
**Why it happens:** IDE auto-formatting or copy-paste from non-const context.
**How to avoid:** Keep `} as const;` on the closing line. After edit, confirm `FilterGroup` still narrows by running `npx tsc --noEmit` in `dashboard/`.

### Pitfall 3: Using wrong event_type string for token_usage
**What goes wrong:** Filter tab is added but never matches events because the string doesn't match what SubagentStop emits.
**Why it happens:** Guessing the event_type string.
**How to avoid:** The canonical string is `token_usage` — confirmed by SubagentStop hook implementation (STATE.md: "SubagentStop emits token_usage event by reading agent_transcript_path JSONL").

### Pitfall 4: Missing REQUIREMENTS.md row for DSH-02 Plan column
**What goes wrong:** Row updated with only `Verified=Yes` but Plan column left as `—`.
**Why it happens:** Fixing only what was explicitly stated in one part of SC-1.
**How to avoid:** SC-1 states "DSH-02 has Plan=135-03, Verified=Yes" — both columns need updating in the same edit.

### EVENT_FILTER_GROUPS — Target State
```typescript
// Source: dashboard/lib/event-types.ts
export const EVENT_FILTER_GROUPS = {
  all: null,
  tools: ['tool_called', 'bash_called', 'file_changed'],
  agents: ['subagent_start', 'subagent_stop'],
  phases: ['session_start', 'session_end'],
  errors: ['error'],
  tokens: ['token_usage'],
} as const;

export type FilterGroup = keyof typeof EVENT_FILTER_GROUPS;

export function filterEvents(events: WireEnvelope[], group: FilterGroup): WireEnvelope[] {
  const allowed = EVENT_FILTER_GROUPS[group];
  if (allowed === null) return events;
  return events.filter((ev) => (allowed as readonly string[]).includes(ev.event_type));
}
```
