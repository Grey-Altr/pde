    The endpoint flow:
    1. Check Bearer token via validateRelayToken(request) from @/lib/auth -- return 401 { error: 'Unauthorized' } if false (per DSH-06)
    2. Parse JSON body with try/catch -- return 400 { error: 'Invalid JSON' } on parse failure
    3. Validate with z.array(WireEnvelopeSchema).min(1).max(100).safeParse(body) -- return 422 { error: result.error.flatten() } on failure (batch size limit 100 per Claude's discretion)
    4. Extract session_id from first event (all events in a batch share the same session_id -- relay sends per-session batches)
    5. Use redis.pipeline() to batch all writes (per D-03):
       - For each event: p.zadd('pde:default:events:' + sessionId, { score: new Date(event.relay_ts).getTime(), member: JSON.stringify(event) }) -- use "default" as user namespace for v0.17 single-user (per D-02, future-proof key structure)
       - p.zadd('pde:default:sessions', { score: Date.now(), member: sessionId }) -- update session registry (per D-01)
       - p.hset('pde:default:session:' + sessionId, { last_event_ts: String(Date.now()), last_event_type: lastEvent.event_type, phase: lastEvent.extensions?.phase_name ?? '', plan: lastEvent.extensions?.plan_name ?? '', started_at: ... }) -- update session metadata hash (per D-01)
    6. await p.exec() -- single round-trip
    7. Return 200 { ok: true, count: validatedBatch.length }

    Add export const dynamic = 'force-dynamic'; at top of file to prevent Vercel caching.
