Create bin/lib/app-registry.cjs as a CJS module with 'use strict'. Registry file path: .planning/app-registry.json (distinct from .planning/cli-anything/registry.json).

**Registry JSON schema:**
```json
{
  "version": 1,
  "entries": [
    {
      "slug": "blender",
      "displayName": "Blender",
      "binaryPath": "/Applications/Blender.app/Contents/MacOS/Blender",
      "version": "4.2.0",
      "executionMode": "headless",
      "status": "pending",
      "binaryHash": null,
      "probeSource": { "tier": 4, "source": "mdfind", "appBundle": "/Applications/Blender.app" },
      "displayProbe": { "available": true, "method": "ps-WindowServer", "probeTime": "2026-03-29T12:00:00.000Z" },
      "parseQuality": "clean",
      "discoveredAt": "2026-03-29T12:00:00.000Z",
      "approvedAt": null,
      "rejectedAt": null
    }
  ]
}
```

**Exports (via module.exports):**

1. `loadRegistry(registryPath, _fns)` - Read and parse JSON. If file missing (ENOENT), return { entries: [], version: 1 }. _fns: { readFn } defaults to fs.readFileSync.

2. `saveRegistry(registryPath, registry, _fns)` - Write JSON with 2-space indent. _fns: { writeFn } defaults to fs.writeFileSync. Creates parent directory if needed via fs.mkdirSync({recursive:true}).

3. `addPendingEntry(registryPath, discoveryResult, _fns)` - Load registry, find existing entry by slug (update if exists, append if not). Set: status='pending', binaryHash=null, discoveredAt=new Date().toISOString(), approvedAt=null, rejectedAt=null. Copy slug, displayName, binaryPath, version, executionMode, probeSource, displayProbe, parseQuality from discoveryResult. Save registry. _fns: { readFn, writeFn }.

4. `approveEntry(registryPath, slug, _fns)` - Load registry, find entry by slug. Throw if not found (message: 'App "slug" not found in registry.\nRun: pde-tools app discover to add it.'). Compute SHA-256 of binaryPath file. Set status='approved', binaryHash=computed hash, approvedAt=new Date().toISOString(). Save. _fns: { readFn, writeFn, hashFn }. Default hashFn uses require('crypto').createHash('sha256').update(fs.readFileSync(path)).digest('hex').

5. `rejectEntry(registryPath, slug, _fns)` - Load registry, find entry by slug. Throw if not found. Set status='rejected', rejectedAt=new Date().toISOString(). Save. _fns: { readFn, writeFn }.

6. `checkApproved(registryPath, slug, _fns)` - Load registry, find entry. Three error cases with actionable messages:
   - Not found: 'App "slug" not found in registry.\nRun: pde-tools app discover to add it.'
   - Not approved: 'App "slug" has status "STATUS" - cannot invoke.\nRun: pde-tools app approve slug to grant execution permission.'
   - Mock executionMode: 'App "slug" has executionMode "mock" - binary not installed or not resolvable.\nInstall the app and re-run: pde-tools app discover'
   - Success: return the entry object.
   _fns: { readFn }.

7. `verifyBinaryHash(binaryPath, expectedHash, _fns)` - Compute SHA-256 of file, compare to expected. Returns { ok: boolean, actual: string, expected: string }. On read error: { ok: false, error: message }. _fns: { hashFn }.

8. `getEntry(registryPath, slug, _fns)` - Load registry, return entry or null. _fns: { readFn }.

9. `listEntries(registryPath, _fns)` - Load registry, return entries array. Optional status filter. _fns: { readFn }.

**Key implementation details:**
- All fs/crypto operations injectable via _fns for testing
- SHA-256 hash computed at approval time ONLY (not discovery) - large binaries like Blender are 200MB+
- binaryHash is null in pending entries - this is correct and intentional
- Error messages include the exact CLI command to run for resolution
- Registry path is always .planning/app-registry.json relative to project root
