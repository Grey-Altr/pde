<objective>
Implement Blender and Inkscape wrapper modules that build version-aware CapabilityModels from approved registry entries. These represent two distinct execution patterns: Blender (headless with --background, async-required, long startup) and Inkscape (pure CLI, no headless flags, fast execution).

Purpose: WRAP-01 (Blender) and WRAP-03 (Inkscape) are the two simpler wrappers — no version-conditional API breaks like GIMP. Building them together maximizes parallelism with GIMP (Plan 03).

Output: Two wrapper modules with full test coverage, ready for generateAppWrapper orchestration from Plan 01.
</objective>

       - `meta.source`: registryEntry.binaryPath
       - `meta.type`: 'cli'
       - `meta.version`: registryEntry.version or 'unknown'
       - `meta.auth`: {}
       - `meta.generatedAt`: ISO timestamp
       - Three capabilities:
         a. **blender_render**: Render a .blend file frame. Path: `blender --background`. Extensions: `{ subcommandPath: ['--background', '--factory-startup'] }`
         b. **blender_python_exec**: Execute Python script in Blender context. Path: `blender --background --python`. Input schema: `blendFile` (string, required), `pythonScript` (string, optional), `pythonExpr` (string, optional). Extensions: `{ subcommandPath: ['--background', '--factory-startup'] }`
         c. **blender_export**: Export scene to format. Path: `blender --background`. Input schema: `blendFile` (string, required), `outputPath` (string, required), `format` (string, required — "FBX", "OBJ", "GLB", etc.), `pythonExpr` (string, optional — custom export script).
       - Call `validateCapabilityModel()` before returning.

    3. `getMetadata(registryEntry)` — returns wrapper metadata:
       ```javascript
       {
         slug: 'blender',
         startupMs: 5000,
         executionMode: registryEntry.executionMode || 'headless',
         asyncRequired: true,
         versionRequires: '3.x|4.x',
         generatedAt: new Date().toISOString(),
       }
       ```

    4. Export: `module.exports = { buildCapabilityModel, getMetadata, parseMajorVersion };`

    **CRITICAL per WRAP-01:** asyncRequired MUST be true. startupMs MUST be 5000. All capabilities MUST include --background and --factory-startup. --python-exit-code 1 MUST be documented in render/python capability descriptions (it gets added by the tool handler at invocation time, not hardcoded into subcommandPath — the handler adds it dynamically).
