    **Step 2: Implement gimp-wrapper.cjs** (GREEN phase)

    Create `bin/lib/app-wrappers/gimp-wrapper.cjs` with:

    1. `parseMajorVersion(versionString)` — extract major version from GIMP version output. Handle "GIMP 2.10.38" and "GNU Image Manipulation Program version 3.0.2" formats. Return `null` for null/undefined.

    2. `buildGimpArgs(scriptFuExpr, registryEntry)` — version-conditional argument builder:
       ```javascript
       function buildGimpArgs(scriptFuExpr, registryEntry) {
         const major = parseMajorVersion(registryEntry.version) || 2;
         const baseArgs = ['--no-interface', '-d', '-f', '--batch', scriptFuExpr];
         if (major >= 3) {
           return [...baseArgs, '--quit'];
         } else {
           return [...baseArgs, '--batch', '(gimp-quit 0)'];
         }
       }
       ```

    3. `getScriptFuTemplates(registryEntry)` — returns version-appropriate Script-Fu template strings:
       ```javascript
       function getScriptFuTemplates(registryEntry) {
         const major = parseMajorVersion(registryEntry.version) || 2;
         if (major >= 3) {
           return {
             fileLoad: '(gimp-file-load RUN-NONINTERACTIVE "{inputPath}")',
             fileExport: '(gimp-file-export RUN-NONINTERACTIVE image (vector drawable) "{outputPath}")',
             getDrawable: '(car (gimp-image-get-active-drawable image))',
             drawableWrap: '(vector drawable)',
             quit: '--quit flag (do NOT use gimp-quit)',
           };
         } else {
           return {
             fileLoad: '(gimp-file-load RUN-NONINTERACTIVE "{inputPath}" "")',
             fileExport: '(file-png-save RUN-NONINTERACTIVE image drawable "{outputPath}" "")',
             getDrawable: '(car (gimp-image-get-active-drawable image))',
             drawableWrap: 'drawable',
             quit: '--batch \'(gimp-quit 0)\' as second batch command',
           };
         }
       }
       ```

    4. `buildCapabilityModel(registryEntry)` — returns validated CapabilityModel with:
       - `meta.source`: registryEntry.binaryPath
       - `meta.type`: 'cli'
       - `meta.version`: registryEntry.version or 'unknown'
       - Two capabilities:
         a. **gimp_batch**: Execute Script-Fu batch expression. Path: `gimp --no-interface`. Input schema: `scriptFu` (string, required — Script-Fu expression), `quit` (string, optional — override quit behavior). Description includes version-specific notes from getScriptFuTemplates. Extensions: `{ subcommandPath: ['--no-interface', '-d', '-f'] }`
         b. **gimp_file_convert**: Convert image file using Script-Fu template. Path: `gimp --no-interface`. Input schema: `inputPath` (string, required), `outputPath` (string, required), `format` (string, optional — "png", "jpg", "tiff"). Description documents the version-specific file-load and file-export patterns.
       - Call `validateCapabilityModel()` before returning.
       - In each capability description, document which GIMP version patterns are used based on the registry entry version.

    5. `getMetadata(registryEntry)` — returns:
       ```javascript
       {
         slug: 'gimp',
         startupMs: 10000, // GIMP startup is 5-30 seconds
         executionMode: registryEntry.executionMode || 'headless',
         asyncRequired: true,
         gimpMajorVersion: parseMajorVersion(registryEntry.version) || 2,
         generatedAt: new Date().toISOString(),
       }
       ```

    6. Export: `module.exports = { buildCapabilityModel, getMetadata, parseMajorVersion, buildGimpArgs, getScriptFuTemplates };`

    **CRITICAL per WRAP-02:**
    - `--quit` is GIMP 3.x ONLY (introduced 2.99.12). NEVER use --quit on GIMP 2.x.
    - `(gimp-quit 0)` is GIMP 2.x pattern. NEVER use (gimp-quit) on GIMP 3.x.
    - GIMP 3.x uses 1-arg gimp-file-load. GIMP 2.x uses 2-arg.
    - GIMP 3.x uses (vector drawable) not bare drawable.
    - GIMP 3.x uses gimp-file-export not file-png-save.
