         - Build scriptFu via `buildRetouchScript({ inputPath: inputPngPath, outputPath: tempOutput, registryEntry })`
         - Get args via `buildGimpArgs(scriptFu, registryEntry)`
         - try/finally block:
           - Spawn GIMP: command = `registryEntry.binaryPath`, args from buildGimpArgs, timeout 60000
